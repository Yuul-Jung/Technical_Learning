Digital / FPGA

  1. SW0를 이용한 LED0 ON/OFF 실습
    Verilog 기본 입출력, assign, XDC 핀 설정, Synthesis → Implementation → Bitstream → Program Device 흐름
  2. 74 시리즈 기반 Verilog RTL 설계 가이드
    Gate → Combinational → Sequential → Project/Peripheral 순서로 RTL 모듈과 프로젝트 구조 정리
  3. 부울대수 공리 FPGA 실습
    SW0와 LED0~LED3를 이용하여 X·1=X, X+0=X, X·0=0, X+1=1을 Verilog로 구현·검증
  4. Level 1 논리게이트 FPGA 실습
    AND · OR · NOT · NAND · NOR · BUFFER를 SW0·SW1과 LED로 구현하고 진리표 검증
  5. 구조화 Gate Module RTL 실습
    74 시리즈 Gate를 독립 Module로 분리하고 gate_top에서 Instance하여 계층적 RTL 구조 구현
  6. Verilog 기본 문법과 로직게이트 실습
    Verilog 문법 및 로직게이트 실습(1)·(2)을 하나의 챕터로 묶어 Module, Port, Vector, wire, assign, 논리연산 정리
  7. Boolean Algebra · Karnaugh Map RTL 실습
    Gate 조합 → 부울대수 → DeMorgan → NAND Universal → SOP/POS → Karnaugh Map 간략화와 전후 회로 비교
  8. 조합회로 설계 실습 — Adder
    Half Adder → Full Adder → 4bit Ripple/Carry Look-Ahead → Seven Segment → Testbench와 Basys3 검증
  9. CLA Adder 원리와 FPGA 실무형 작성법
    Ripple Carry → Carry Look-Ahead 원리 → 직접 Carry 식 → + 연산자 기반 실무형 RTL → 32비트 확장
  10. Verilog Testbench 기본 개념
    Testbench → DUT Instance → reg/wire → 포트 매핑 → initial 입력 자극 → Simulation 결과 확인
  11. Selection · Conversion Logic RTL 실습
    MUX → DEMUX → Decoder → Encoder → Comparator → 확장 MUX/Decoder → Mini ALU 조합회로 설계
  12. 조합회로 응용 Mini Project
    요구사항 → 시스템 설계 → Verilog → Testbench → RTL Schematic → Basys3 검증으로 Level 2 조합회로 종합 실습
  13. Tri-State Buffer · Shared Bus RTL 실습
    High-Z(Z) → Enable → Shared Bus → Bus Contention 개념 → Testbench → FPGA 내부 MUX 합성 구조 확인
  14. 순차회로와 Latch 기초
    조합회로의 한계 → State/Memory → SR Latch → Level Sensitive → Inferred Latch → Simulation 검증
  15. D Flip-Flop · Edge Triggered RTL 실습
    Latch → Clock Edge → D Flip-Flop → posedge → Non-blocking Assignment → Reset → Waveform 검증
  16. 8bit Register · Enable · Load · Reset RTL 실습
    D Flip-Flop 확장 → 8bit 저장 → Enable/Hold → Load → Reset/Clear → FPGA의 Register + 조합논리 구조
  17. Shift Register · Serial/Parallel 변환 RTL 실습
    Register → Shift Left/Right → SISO/SIPO/PISO → Universal Shift Register → Basys3 수동 동작 검증
  18. Counter Step 1 · Tick · BCD · FND RTL 실습
    Tick 생성 → 1Hz Enable/Blink 구분 → Up Counter → Reset/Enable → Mod-10 BCD → Basys3 FND 종합
  19. Counter Step 2 · Multi-Digit BCD · FND Multiplexing
    2자리 BCD → 4자리 BCD → 자리 올림 → Digit 선택 → FND Multiplexing → Basys3 4자리 종합
  20. Stopwatch Step 3 · 4자리 구조화 RTL 실습
    10ms Tick → Start/Stop 상태 저장 → 4자리 Stopwatch Counter → FND Scan/MUX/Decoder → Basys3 Top
  21. Button Debounce · 2-FF Synchronizer · One-Pulse RTL
    Button Bounce → 2-FF 동기화 → Debounce Counter → 안정 상태 → Rising Edge → 1-Clock Pulse
  22. 24시간 디지털 시계 · HH:MM RTL 실습
    1초 Tick → 60초 Counter → 1분 Tick → 24시간 HH:MM Counter → 1Hz DP Blink → Basys3 FND
  23. FSM 회로 설계 · Moore · Mealy RTL 실습
    State Register → Next State Logic → Output Logic → Moore FSM → Mealy FSM → Simulation 검증
