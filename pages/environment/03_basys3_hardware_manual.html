STEP 01

1. Basys3 보드의 위치

Basys3는 AMD/Xilinx Artix-7 XC7A35T-1CPG236C를 사용하는 교육용 FPGA 보드입니다. 기본 조합회로부터 순차회로, UART, VGA, XADC, Soft Processor까지 단계적으로 확장할 수 있습니다.

STEP 04

4. FPGA Programming 방식

Reference Manual은 Basys3 FPGA 설정 경로를 여러 방식으로 설명합니다.

방식특징실습 우선순위
USB-JTAGPC에서 Hardware Manager로 즉시 Program기본
SPI FlashBitstream을 비휘발성 Flash에 저장확장
USB Memory지원 Mode에서 저장장치 Bitstream 사용필요 시
JTAG로 FPGA SRAM에 Program한 Bitstream은 전원이 꺼지면 사라집니다. 전원 재인가 후 자동 동작이 필요하면 Serial Flash Programming을 사용합니다.
STEP 05

5. 전원과 Programming Jumper

  • 보드 전원은 USB 또는 외부 5V 계열 전원으로 공급할 수 있습니다.
  • 전원 선택 Jumper와 Programming Mode Jumper의 위치를 작업 전에 확인합니다.
  • 외부 센서와 모터를 연결할 때는 Basys3 USB 전원만으로 전체 부하를 공급하지 않습니다.
  • 전원 LED와 DONE LED를 통해 기본 상태를 확인합니다.

STEP 07

7. 실습 전 하드웨어 체크리스트

  • 보드가 Basys3 Rev와 일치하는지 확인
  • USB 케이블이 Data 통신을 지원하는지 확인
  • JP1/JP2 Jumper 위치 확인
  • PMOD/JXADC 핀의 전압 기준 확인
  • 외부 5V 센서의 Level Shifter 필요 여부 확인
  • 모터·릴레이 등 대전류 부하는 외부 Driver 사용

핵심 정리

  • Basys3의 중심 FPGA는 Artix-7 XC7A35T-1CPG236C입니다.
  • 보드 자체 I/O만으로도 많은 디지털 회로 실습이 가능합니다.
  • PMOD, XADC, VGA, UART, Flash를 이용해 주변기기와 시스템 설계로 확장합니다.
  • Reference Manual, Schematic, XDC는 서로 연결해서 봅니다.
