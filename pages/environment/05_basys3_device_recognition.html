Basys3 보드 인식 흐름

Vivado→ Adept Runtime→ USB Data Cable→ Basys3 JTAG
STEP 01

1. 가장 먼저 확인할 증상

  • Vivado Hardware Manager에서 Board가 보이지 않음
  • Open Target 또는 Auto Connect 실패
  • USB 연결 후 Programming Device가 나타나지 않음

참고자료는 이런 경우 Digilent Adept Runtime 설치 여부를 가장 먼저 확인하도록 설명합니다.

STEP 02

2. Adept Runtime의 역할

Adept Runtime은 Digilent FPGA Board와 PC 사이의 USB 통신을 담당하는 Runtime/Driver 계층입니다. Vivado가 Basys3 JTAG 장치를 인식하는 데 필요한 구성 요소입니다. 

PC / Vivado
→ Adept Runtime
→ USB
→ Basys3
→ Artix-7 FPGA
STEP 03

3. 설치와 재연결 절차

  1. Digilent Adept 공식 페이지에서 Runtime을 준비합니다.
  2. OS에 맞는 Runtime을 설치합니다.
  3. Basys3 USB 케이블을 분리합니다.
  4. 다시 연결합니다.
  5. Vivado를 다시 실행합니다.
  6. Hardware Manager → Open Target → Auto Connect를 실행합니다.

Digilent Adept 공식 페이지 열기

STEP 04

4. Ubuntu에서 장치 확인

# USB 장치 확인
lsusb

# Digilent 장치 확인
djtgcfg enum

# Serial Device 후보 확인
ls /dev/ttyUSB*
ls /dev/ttyACM*
djtgcfg enum은 Digilent JTAG/보드 인식 확인에 사용하고, /dev/ttyUSB* 또는 /dev/ttyACM*은 UART Serial Port 확인에 사용합니다.
STEP 05

5. 다운로드 인식과 UART Serial 인식은 구분

목적경로대표 확인
FPGA Program/JTAGVivado ↔ Adept Runtime ↔ USB-JTAGHardware Manager, djtgcfg enum
UART Serial 통신Terminal ↔ OS Serial Device ↔ USB-UART/dev/ttyUSB*, COM Port
검증 메모: 원본 페이지 제목에는 “시리얼포트 인식”이라고 되어 있지만 본문은 주로 Vivado Hardware Manager와 Adept Runtime을 이용한 FPGA 다운로드/JTAG 장치 인식을 설명합니다. UART Serial Port 인식과는 목적과 장치 경로가 다르므로 공개본에서는 두 경로를 분리해서 설명합니다.
STEP 06

6. 인식이 안 될 때 체크리스트

  • USB 케이블이 충전 전용이 아니라 Data 통신용인지 확인
  • 다른 USB Port 사용
  • Basys3 Power LED 확인
  • Adept Runtime 설치 확인
  • Vivado 재시작
  • Ubuntu 권한 그룹과 udev/Driver 설정 확인
  • Board Programming Jumper 위치 확인

핵심 정리

  • Vivado에서 Basys3가 보이지 않으면 Runtime과 USB 연결을 먼저 확인합니다.
  • JTAG/다운로드 인식과 UART Serial Port 인식은 서로 다른 경로입니다.
  • djtgcfg enum은 Digilent Board 인식 확인에 유용합니다.
  • Hardware Manager의 Auto Connect까지 성공하면 다운로드 준비가 완료됩니다.
