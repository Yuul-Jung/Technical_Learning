XDC의 역할

RTL Port→ get_ports→ PACKAGE_PIN→ IOSTANDARD→ Physical Pin
STEP 01

1. XDC 한 줄 정의

FPGA 내부 신호를 실제 보드 핀에 연결하고, Clock과 Timing 조건을 정의하는 파일입니다.

XDC는 Xilinx Design Constraints의 약자이며 Vivado에서 사용하는 Tcl 기반 Constraint 형식입니다.

STEP 02

2. XDC의 두 가지 핵심 역할

역할예
Pin ConstraintSW0 → V17, LED0 → U16
Timing Constraint100MHz Clock → Period 10ns
STEP 03

3. SW0 → LED0 실제 예

## Switch SW0
set_property PACKAGE_PIN V17 [get_ports {sw[0]}]
set_property IOSTANDARD LVCMOS33 [get_ports {sw[0]}]

## LED0
set_property PACKAGE_PIN U16 [get_ports {led[0]}]
set_property IOSTANDARD LVCMOS33 [get_ports {led[0]}]
문법의미
PACKAGE_PINFPGA Package의 실제 Pin 위치
IOSTANDARDI/O 전압·전기 규격
get_portsTop Module 외부 Port 선택
STEP 04

4. 100MHz Clock Constraint

set_property -dict { PACKAGE_PIN W5 IOSTANDARD LVCMOS33 } [get_ports clk]

create_clock -add -name sys_clk_pin \
    -period 10.00 -waveform {0 5} [get_ports clk]
100 MHz → 1 / 100,000,000 s → 10 ns → create_clock -period 10.00
STEP 05

5. Basys-3-Master.xdc 사용 원칙

  1. Digilent의 Basys-3-Master.xdc를 프로젝트에 추가합니다.
  2. 사용하는 Pin의 주석만 해제합니다.
  3. get_ports 이름을 Top Module Port와 정확히 맞춥니다.
  4. 사용하지 않는 Pin은 계속 주석 상태로 둡니다.
  5. Clock은 Pin뿐 아니라 create_clock도 함께 설정합니다.

핵심 정리

  • XDC는 HDL과 실제 보드 하드웨어를 연결합니다.
  • Pin Assignment와 Timing Constraint가 핵심입니다.
  • Top Port 이름과 get_ports 이름은 반드시 같아야 합니다.
  • Basys3에서는 Digilent Master XDC를 기준으로 필요한 항목만 활성화합니다.
