Digilent Adept 구성

Vivado / User Program→ Adept Runtime→ USB→ Basys3
STEP 01

1. Adept란 무엇인가

Digilent Adept는 PC에서 Digilent FPGA Board를 연결하고 설정·통신·Programming하기 위한 소프트웨어 구성입니다. 실습에서 가장 중요한 구성 요소는 Board 인식에 필요한 Runtime입니다.

STEP 02

2. Runtime

항목내용
역할USB Runtime / Driver 계층
목적PC가 Digilent FPGA Board를 인식
VivadoHardware Manager 연결에 중요
문제 시Open Target 실패, Board 미인식
STEP 03

3. Utilities

Adept Utilities는 Digilent Device를 검색하고 통신·테스트하는 Command Line 도구를 제공합니다.

# Digilent 장치 열거
djtgcfg enum

# 실행 파일 위치 확인
which djtgcfg
STEP 04

4. SDK

Adept SDK는 C/C++ 등의 사용자 프로그램에서 Digilent Device와 통신하기 위한 API를 제공합니다. 일반적인 Verilog RTL 실습에서는 필수는 아니지만 자동화 도구나 자체 Programming/통신 Software를 만들 때 사용할 수 있습니다.

→ 과거 GUI 도구
→ 현재 실습에서는 주력 도구로 사용하지 않음
STEP 07

7. 환경구축 완료 기준

  • Vivado가 정상 실행됩니다.
  • Basys3가 USB Data Cable로 연결됩니다.
  • djtgcfg enum에서 Digilent 장치가 확인됩니다.
  • Vivado Hardware Manager에서 Auto Connect가 동작합니다.
  • 다음 Digital / FPGA 실습에서 Bitstream을 Program할 수 있습니다.

핵심 정리

  • Adept의 핵심은 Runtime, Utilities, SDK 역할을 구분하는 것입니다.
  • RTL 실습에서 가장 먼저 필요한 것은 Runtime 기반 Board 인식입니다.
  • Utilities의 djtgcfg로 장치 인식을 확인할 수 있습니다.
  • 환경구축 및 하드웨어 단계가 끝나면 Digital / FPGA 01 실습으로 이동합니다.
