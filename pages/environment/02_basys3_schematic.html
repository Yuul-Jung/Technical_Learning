STEP 01

1. Basys3 회로도 문서의 역할

Basys3 회로도는 보드의 스위치, 버튼, LED, PMOD, XADC, VGA, USB, Flash, 전원 회로가 Artix-7 FPGA의 어떤 Bank와 Package Pin에 연결되어 있는지 확인하는 기준 문서입니다.

보드 실습에서 핀 번호를 임의로 외우기보다 회로도 → XDC → RTL Port 순서로 확인하는 습관을 만듭니다.

STEP 03

3. PMOD / I/O 회로 읽기

외부 PMOD Pin
→ 보호/직렬 저항
→ FPGA I/O Net
→ Artix-7 Package Pin
→ XDC PACKAGE_PIN
→ Verilog Top Port

공식 회로도의 PMOD/I/O Sheet에는 JA, JB, JC, JXADC와 16개 Switch, 5개 Push Button이 함께 정리되어 있습니다. PMOD 디지털 I/O는 3.3V 기준이며, JXADC는 일반 PMOD와 다른 Analog 입력 용도입니다.

STEP 04

4. 회로도와 XDC 연결 예

SW0
→ Basys3 회로도에서 SW0 Net 확인
→ FPGA Package Pin V17
→ XDC

set_property PACKAGE_PIN V17 [get_ports {sw[0]}]
set_property IOSTANDARD LVCMOS33 [get_ports {sw[0]}]
주의: 회로도의 Net 이름과 RTL Port 이름이 항상 동일한 것은 아닙니다. Vivado에서 실제 사용하는 이름은 XDC의 get_ports와 Top Module Port 이름이 정확히 일치해야 합니다.
STEP 05

5. 회로도 Sheet를 볼 때의 순서

  1. 사용하려는 커넥터나 주변장치를 찾습니다.
  2. Net 이름과 전압 기준을 확인합니다.
  3. FPGA Bank와 Package Pin을 확인합니다.
  4. Digilent Master XDC의 해당 항목과 대조합니다.
  5. Top Module Port 이름으로 XDC를 맞춥니다.
  6. 외부 5V 장치라면 Level Shifting 필요 여부를 별도로 확인합니다.

핵심 정리

  • 회로도는 보드의 실제 전기 연결을 확인하는 기준 문서입니다.
  • Pin 정보는 회로도와 Master XDC를 함께 확인합니다.
  • PMOD는 3.3V 디지털 I/O, JXADC는 Analog 입력이라는 차이를 구분합니다.
  • 외부 장치 연결 전에는 전압과 방향을 먼저 확인합니다.
