환경구축 및 하드웨어 · 01

Ubuntu에서 AMD Vivado 2024.2 설치

Ubuntu 24.04 환경에서 Vivado를 설치하고, 케이블 드라이버와 Digilent 도구를 준비하여 Basys3 보드 인식까지 확인합니다.

Ubuntu 24.04Vivado 2024.2Basys3Artix-7

시작 조건

Ubuntu 설치, 인터넷 연결, sudo 권한, Basys3와 USB 데이터 케이블을 준비합니다.

핵심 설치

필수 패키지 → Vivado → 환경 변수 → 케이블 드라이버 순서로 진행합니다.

완료 기준

Vivado 실행과 Basys3 장치 인식을 확인하면 환경구축이 완료됩니다.

전체 설치 흐름

시스템 준비→필수 패키지→Vivado 설치→환경설정→케이블 드라이버→Digilent Runtime→Basys3 인식

1. 개요

다운로드 → 시스템 준비 → 필수 패키지 → Vivado 설치 → 환경설정 → 케이블 드라이버 → Digilent Runtime → Basys3 인식
  • 대상 환경: Ubuntu 24.04 64-bit
  • 개발 도구: AMD Vivado 2024.2
  • 대상 보드: Digilent Basys3
  • FPGA: AMD/Xilinx Artix-7 계열
AMD의 Vivado 2024.2 지원 운영체제 목록에는 Ubuntu 24.04 LTS 64-bit가 포함됩니다.

2. 사전 준비

STEP 0
  • Ubuntu 24.04 설치 완료
  • 인터넷 연결
  • sudo 사용 가능한 관리자 권한
  • Basys3 보드
  • 데이터 통신이 가능한 USB 케이블
주의: 단순 충전·전원 전용 케이블은 JTAG/USB 통신에 사용할 수 없습니다.
STEP 1

터미널 실행

Ctrl + Alt + T

3. 시스템 업데이트와 필수 패키지

STEP 2

시스템 업데이트

sudo apt update
sudo apt upgrade -y
  • 패키지 목록 최신화
  • 설치 전 시스템 상태 정리
STEP 3

필수 패키지 설치

sudo apt install -y build-essential git make gcc g++ \
  libncurses6 libtinfo6 libusb-1.0-0 libgtk-3-0 \
  libx11-6 libxext6 libxrender1 libxtst6 libxi6 \
  libxft2 net-tools
패키지역할
build-essential, gcc, g++, make컴파일·빌드 기본 환경
libusb-1.0-0USB 통신 지원
libgtk-3-0, X11 관련 라이브러리Vivado GUI 실행 지원
libncurses6, libtinfo6터미널 기능 지원
git, net-tools소스 관리·네트워크 확인용

4. Vivado 설치

STEP 4

설치 파일 준비

  • AMD 공식 다운로드 페이지에서 Vivado 2024.2 Linux 설치 파일 다운로드
  • 기본 다운로드 위치: ~/Downloads
  • 예상 파일명: FPGAs_AdaptiveSoCs_Unified_2024.2_*.bin
STEP 5

실행 권한 부여

cd ~/Downloads
chmod +x FPGAs_AdaptiveSoCs_Unified_2024.2_*.bin
STEP 6

설치 프로그램 실행

./FPGAs_AdaptiveSoCs_Unified_2024.2_*.bin
일반 Vivado 설치 프로그램 자체는 Linux에서 root 권한 없이 실행할 수 있습니다. 케이블 드라이버 설치는 설치 완료 후 별도로 sudo 권한을 사용합니다.
STEP 7

설치 옵션

  • Vivado 설치 선택
  • Basys3 사용을 위해 7 Series 디바이스 지원 포함
  • Basys3의 FPGA는 Artix-7 계열이므로 해당 디바이스 지원이 필요
  • 설치 경로 예: /tools/Xilinx

5. 환경설정과 실행 확인

STEP 8

환경 변수 적용

source /tools/Xilinx/Vivado/2024.2/settings64.sh

현재 터미널 세션에 Vivado 실행 경로와 관련 환경을 등록합니다.

STEP 9

Vivado 실행

vivado
Vivado GUI가 정상적으로 열리면 기본 설치가 완료된 상태입니다.

6. 케이블 드라이버 설치

STEP 10

Linux에서는 Vivado 설치 후 케이블 드라이버 설치 스크립트를 별도로 실행합니다.

cd /tools/Xilinx/Vivado/2024.2/data/xicom/cable_drivers/lin64/install_script/install_drivers
sudo ./install_drivers
AMD 문서에서도 Linux 케이블 드라이버는 Vivado 설치 후 별도 스크립트를 root 또는 sudo 권한으로 실행하도록 안내합니다.

7. Digilent Runtime과 Basys3 인식

STEP 11

Adept Runtime / Utilities 준비

  • Digilent Adept Runtime 설치
  • djtgcfg 확인을 위해 Adept Utilities도 설치
  • 다운로드한 .deb 파일은 보통 ~/Downloads에 위치
cd ~/Downloads
sudo dpkg -i digilent.adept.runtime_*.deb
sudo apt -f install

sudo dpkg -i digilent.adept.utilities_*.deb
sudo apt -f install

설치 확인

which djtgcfg

실행 파일 경로가 출력되면 Utilities 설치가 확인된 것입니다.

STEP 12

Basys3 검색

djtgcfg enum
STEP 13

사용자 권한 설정

sudo usermod -aG dialout $USER
sudo usermod -aG plugdev $USER

그룹 변경 후에는 로그아웃/로그인 또는 재부팅하여 권한을 다시 적용합니다.

STEP 14

최종 보드 인식 확인

lsusb
djtgcfg enum
USB 장치와 Digilent 장치가 정상적으로 표시되면 Basys3 연결 준비가 완료된 것입니다.

8. 최종 확인

STEP 15
  • Vivado 프로젝트 생성 또는 준비된 테스트 프로젝트 사용
  • Basys3가 USB 데이터 케이블로 연결되어 있는지 확인
  • Vivado 실행이 정상적인지 확인
  • lsusb와 djtgcfg enum에서 보드 인식 상태 확인

문제 확인 기준

증상우선 확인
vivado: command not foundsettings64.sh 적용 여부
djtgcfg: command not foundAdept Utilities 설치 여부
장치가 검색되지 않음USB 데이터 케이블, 케이블 드라이버, Runtime, 사용자 권한
권한 오류dialout, plugdev 그룹 및 재로그인/재부팅

9. 검증 메모

원본 기술자료의 절차는 유지하되, 공개 페이지에서는 실행 오류를 막기 위해 다음 명령 표기를 교정했습니다.

원문 표기공개본 표기이유
sudo apt install-y ...sudo apt install -y ...install과 -y 사이 공백 필요
sudo dpkg-i ...sudo dpkg -i ...dpkg와 -i 사이 공백 필요
sudo apt-f installsudo apt -f installapt와 -f 사이 공백 필요
Notion 내부 관리 정보, 실명 표기, 특정 공유방·특정 대상 표현은 공개본에서 제거했습니다. 저자 표기는 허용된 형태인 PE. JUNG만 사용합니다.

핵심 정리

  • Vivado가 정상 실행되면 소프트웨어 설치를 확인할 수 있습니다.
  • lsusb와 djtgcfg enum에서 Basys3 연결 상태를 확인합니다.
  • 다음 단계는 실제 Vivado 프로젝트를 이용한 FPGA 실습입니다.
