STEP 02

2. 2자리 BCD Counter — 00~99

if (enable && tick) begin
    if (digit0 == 4'd9) begin
        digit0 <= 4'd0;

        if (digit1 == 4'd9)
            digit1 <= 4'd0;
        else
            digit1 <= digit1 + 1'b1;
    end
    else begin
        digit0 <= digit0 + 1'b1;
    end
end
08 → 09 → 10 → ... → 98 → 99 → 00

digit0은 1의 자리, digit1은 10의 자리입니다. 1의 자리가 9에서 0으로 돌아갈 때만 10의 자리가 증가합니다.

STEP 04

4. FND Multiplexing — Digit 선택

Basys3의 4자리 FND는 Segment 선을 공유하므로 한 순간에는 한 자리만 선택하고, 빠르게 순환하여 동시에 켜진 것처럼 보이게 합니다.

case (digit_sel)
    2'd0: begin current_digit = digit0; an = 4'b1110; end
    2'd1: begin current_digit = digit1; an = 4'b1101; end
    2'd2: begin current_digit = digit2; an = 4'b1011; end
    2'd3: begin current_digit = digit3; an = 4'b0111; end
endcase
digit_sel → 현재 BCD 선택 → current_digit → 해당 an 활성화
STEP 05

5. 선택된 Digit을 7-Segment 코드로 변환

case (current_digit)
    4'd0: seg = 7'b1000000;
    4'd1: seg = 7'b1111001;
    4'd2: seg = 7'b0100100;
    ...
    4'd9: seg = 7'b0010000;
    default: seg = 7'b1111111;
endcase

먼저 어떤 BCD Digit을 표시할지 선택하고, 그 값을 동일한 7-Segment Decoder에 넣습니다. 따라서 4개 Decoder를 따로 둘 필요가 없습니다.

STEP 06

6. FND Scan Counter

always @(posedge clk) begin
    if (btnU) begin
        scan_div <= 16'd0;
        digit_sel <= 2'd0;
    end
    else begin
        scan_div <= scan_div + 1'b1;
        digit_sel <= scan_div[15:14];
    end
end
100MHz Clock → scan_div 증가 → 상위 2bit → 00,01,10,11 → 4자리 반복 선택
Scan은 표시를 위한 빠른 반복 동작이고, 0.1초 Counter 증가는 사람이 확인할 수 있는 느린 동작입니다.

핵심 정리

  • 2자리 BCD Counter는 낮은 자리의 9→0 전환을 다음 자리 증가 조건으로 사용합니다.
  • 4자리 BCD Counter는 같은 자리 올림 구조를 4단계로 확장합니다.
  • FND Multiplexing은 4자리 중 하나를 빠르게 선택하고 동일 Segment Decoder를 공유합니다.
  • Counter 증가 Tick과 FND Scan은 서로 다른 목적의 제어 신호이지만 동일한 기준 Clock Domain에서 동작합니다.
  • 0.1초 Count 기준은 0.05초 Tick 2회로 생성하며, 100MHz에서 0.05초 비교값은 4,999,999입니다.
  • 이 구조는 이후 시계·타이머·스톱워치와 같은 다자리 표시 시스템의 기본이 됩니다.
