FSM 회로 설계 · Moore · Mealy RTL 실습

FSM(Finite State Machine, 유한상태머신)을 현재상태 레지스터, 차기상태 논리, 출력논리의 3개 블록으로 나누어 설계하고 Moore FSM과 Mealy FSM의 출력 결정 방식을 비교합니다.

FSM Present State Next State Moore Mealy

State Register

현재 상태를 Flip-Flop에 저장하고 Clock 상승 Edge에서만 상태를 갱신합니다.

Next State Logic

현재 상태와 입력을 이용하여 다음 상태를 조합논리로 미리 계산합니다.

Output Logic

Moore는 현재 상태, Mealy는 현재 상태와 입력을 이용해 출력을 만듭니다.

FSM 전체 구조

Input→ Next State Logic→ State Register→ Present State→ Output Logic
STEP 01

1. FSM이 필요한 이유

조합회로는 현재 입력만으로 출력이 결정되지만, FSM은 시스템이 지금 어느 단계에 있는지를 상태로 기억하고 입력 조건에 따라 다음 동작을 결정합니다.

회로특징예
조합회로현재 입력만 사용MUX, Decoder, Adder
RegisterClock에 맞추어 값 저장데이터 저장
Counter정해진 순서로 상태 증가시간·개수 Count
FSM조건에 따라 상태 전이제어기·통신 제어·모드 제어
STEP 02

2. FSM의 3개 구성 요소

구성 요소역할회로 종류
현재상태 레지스터현재 상태 저장순차회로
차기상태 논리회로다음 상태 계산조합회로
출력회로출력 생성조합회로
현재상태 PS + 입력 → 차기상태 NS 계산 → Clock 상승 Edge → NS가 새로운 PS로 저장
STEP 03

3. Present State와 Next State

always @(posedge clk) begin
    if (reset)
        current_state <= S0;
    else
        current_state <= next_state;
end
신호의미
current_statePS(Present State, 현재상태)
next_stateNS(Next State, 차기상태)
clk상태 변경 기준 Clock
<=순차회로용 Non-blocking Assignment
입력이 바뀌어도 현재상태가 즉시 바뀌는 것이 아닙니다. 조합논리가 NS를 계산하고 다음 Clock 상승 Edge에서 NS가 PS로 저장됩니다.
STEP 04

4. FSM 3-Block RTL 작성 기준

① State Register — 순차논리

always @(posedge clk) begin
    if (reset)
        current_state <= S0;
    else
        current_state <= next_state;
end

② Next State Logic — 조합논리

always @(*) begin
    next_state = current_state;

    case (current_state)
        ...
        default: next_state = S0;
    endcase
end

③ Output Logic

always @(*) begin
    ...
end
코딩 가이드: 초기 상태를 명확히 정의하고, 조합논리 시작 부분에서 기본값을 먼저 대입하며, case에는 default를 두어 정의되지 않은 상태에서 초기 상태로 복구합니다.

상태 이름은 직접 숫자를 쓰기보다 localparam S0, S1, IDLE, RUN처럼 의미 있는 이름으로 정의합니다.

STEP 05

5. Moore FSM — 버튼 3회 누름 감지기

Moore FSM은 출력이 현재 상태만으로 결정됩니다.

출력 = f(현재상태)

S0 : z = 0
S1 : z = 0
S2 : z = 0
S3 : z = 1
S0 --x=1→ S1 --x=1→ S2 --x=1→ S3(z=1) → S0 
always @(*) begin
    case (current_state)
        S0: z = 1'b0;
        S1: z = 1'b0;
        S2: z = 1'b0;
        S3: z = 1'b1;
        default: z = 1'b0;
    endcase
end

버튼 입력이 없으면 S0·S1·S2에서 현재 상태를 유지하고, 세 번째 입력이 들어오면 S3로 이동합니다. S3에서 출력 z=1을 만든 뒤 다음 상태는 S0입니다.

STEP 06

6. Mealy FSM — 동기식 직렬 데이터 수신기

Mealy FSM은 출력이 현재 상태와 현재 입력을 함께 보고 결정됩니다.

출력 = f(현재상태, 입력)
입력 패턴의미
11짧은 정상 프레임
101긴 정상 프레임
100오류 프레임
출력 y의미
00판정 없음
10유효 비트 1 수신
01긴 프레임 확인 또는 오류 복귀
11정상 프레임 수신 완료
Mealy 상태는 지금까지 수신한 비트 패턴을 기억하는 역할을 합니다. 예를 들어 S1에서 다음 입력이 0이면 지금까지의 비트열이 10이므로 S3으로 이동합니다.

핵심 정리

  • FSM은 조건에 따라 상태를 이동하며 시스템의 제어 순서를 구현하는 순차회로 설계 방법입니다.
  • FSM은 State Register, Next State Logic, Output Logic의 3개 블록으로 나누어 작성합니다.
  • PS는 Clock 상승 Edge에서만 바뀌고 NS는 현재 상태와 입력으로 미리 계산됩니다.
  • Moore FSM은 출력이 현재 상태만으로 결정됩니다.
  • Mealy FSM은 출력이 현재 상태와 입력을 함께 보고 결정됩니다.
  • 초기 상태, 기본값, default, 의미 있는 상태 이름을 명확히 두는 것이 중요합니다.
