Level 1 논리게이트 FPGA 실습

Basys3의 SW0·SW1을 입력으로 사용하여 AND, OR, NOT, NAND, NOR, BUFFER를 Verilog HDL로 구현하고 LED 출력으로 직접 확인합니다.

Logic Gate Truth Table Verilog HDL Basys3

입력

sw[0], sw[1] 두 개의 1비트 입력을 사용합니다.

핵심 연산

&, |, ~ 연산으로 기본 논리게이트를 구현합니다.

확인 방법

입력 조합을 바꾸면서 LED 출력이 각 게이트의 진리표와 일치하는지 확인합니다.

STEP 01

1. 논리게이트란?

디지털 시스템은 0과 1의 전기 신호를 이용해 계산과 판단을 수행하며, 이러한 기본 논리 연산을 수행하는 회로가 논리게이트입니다.

종류기능
AND모든 입력이 1일 때만 1
OR하나라도 1이면 1
NOT입력을 반전
NANDAND 결과를 반전
NOROR 결과를 반전
BUFFER입력을 그대로 출력
원본 자료의 논리기호 이미지는 Notion의 임시 URL로 제공되므로 GitHub Pages 공개본에는 직접 연결하지 않았습니다. 이후 검증된 회로 기호 이미지를 Repository의 images/에 저장한 뒤 추가하는 방식이 안전합니다.

STEP 03

3. Verilog RTL 작성

원본 실습에서는 SW0·SW1을 입력으로 사용하고 여러 LED에 게이트 결과를 동시에 표시합니다. 

module logic_gate_lab(
    input  wire [1:0] sw,
    output wire [7:0] led
);

assign led[0] =  sw[0] & sw[1];        // AND
assign led[1] =  sw[0] | sw[1];        // OR
assign led[2] = ~sw[0];                // NOT X
assign led[3] = ~sw[1];                // NOT Y
assign led[4] = ~(sw[0] & sw[1]);       // NAND
assign led[5] = ~(sw[0] | sw[1]);       // NOR
assign led[6] =  sw[0];                // BUFFER

// LED7은 다음 XOR 확장 실습에서 사용
assign led[7] =  sw[0] ^ sw[1];        // XOR

endmodule

코드 풀이

연산자의미예
&ANDsw[0] & sw[1]
|ORsw[0] | sw[1]
~NOT~sw[0]
^XORsw[0] ^ sw[1]
검증 메모: 원본 페이지의 기본 게이트 실습과 XOR/XNOR 확장 실습이 같은 페이지에 포함되어 있습니다. 공개본에서는 기본 게이트 결과를 LED0~LED6에 두고, LED7은 XOR 확장 확인용으로 연결했습니다.

5. Synthesis · Implementation · Bitstream

Run Synthesis → Run Implementation → Generate Bitstream

작성한 논리식이 FPGA 내부의 실제 논리 자원으로 합성되고 배치·배선된 뒤 Bitstream으로 생성됩니다.

STEP 06

6. 보드에서 동작 검증

Hardware Manager에서 Basys3를 연결하고 Bitstream을 다운로드합니다.

Open Hardware Manager → Auto Connect → Program Device

이후 SW0·SW1을 다음 네 조합으로 변경합니다.

SW0SW1확인
00AND=0, OR=0, NAND=1, NOR=1
01AND=0, OR=1, NAND=1, NOR=0
10AND=0, OR=1, NAND=1, NOR=0
11AND=1, OR=1, NAND=0, NOR=0
NOT X, NOT Y, BUFFER도 각각 입력 신호와 비교하면서 동시에 확인합니다.
STEP 07

7. 추가 실습 — XOR / XNOR

원본 페이지에는 기본 게이트 실습 뒤에 XOR/XNOR 구현 예제가 이어집니다.

// 기본 XOR
assign led[0] = sw[0] ^ sw[1];

// 기본 XNOR
assign led[1] = ~(sw[0] ^ sw[1]);
XYXORXNOR
0001
0110
1010
1101

XOR의 다른 표현

assign led[2] =
    (sw[0] & ~sw[1]) |
    (~sw[0] & sw[1]);

XOR은 두 입력이 서로 다를 때 1이 됩니다. 이 표현은 기본 게이트의 조합으로 XOR을 구성하는 방법을 보여줍니다.

STEP 08

핵심 정리

  • 논리게이트는 디지털 시스템의 가장 기본적인 계산·판단 회로입니다.
  • AND, OR, NOT으로 기본 논리를 만들고 NAND, NOR는 해당 결과를 반전합니다.
  • BUFFER는 입력을 그대로 전달합니다.
  • Verilog의 &, |, ~, ^ 연산자로 게이트 동작을 직접 표현할 수 있습니다.
  • Basys3에서 SW 입력과 LED 출력을 연결하면 진리표를 실제 하드웨어에서 바로 검증할 수 있습니다.
  • 다음 단계에서는 개별 연산식을 재사용 가능한 게이트 모듈로 구조화하는 방향으로 확장합니다.
