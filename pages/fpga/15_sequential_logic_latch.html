순차회로와 Latch 기초

조합회로의 한계를 확인하고, 이전 상태를 기억하는 순차회로와 SR Latch의 기본 동작을 이해합니다. 이어서 Level Sensitive 특성과 의도치 않은 Inferred Latch가 왜 FPGA RTL에서 문제가 되는지 Simulation으로 확인합니다.

STEP 01

1. 조합회로의 한계

조합회로는 출력이 현재 입력값에만 의존합니다.

출력 → 현재 입력의 함수
항목조합회로
기억 기능없음
상태없음
Clock사용하지 않음
출력 변화입력 변화가 바로 반영됨

AND, OR, XOR, MUX, Decoder, Adder처럼 지금까지 학습한 회로는 모두 이 범주에 속합니다.

디지털 시계의 현재 시간, UART의 현재 비트 위치, 자판기의 투입 금액, CPU의 현재 명령 상태처럼 과거 정보를 유지해야 하는 시스템은 조합회로만으로 구현할 수 없습니다.
STEP 02

순차회로는 현재 입력뿐 아니라 이전 상태를 함께 사용합니다.

출력 → 현재 입력 + 이전 상태
용어의미

Memory이전 상태를 저장하는 기능

대표적인 저장 요소는 Latch와 Flip-Flop입니다. 이번 장에서는 먼저 가장 기본적인 Latch의 기억 원리를 확인합니다.

STEP 03

3. SR Latch 기본 동작

SR Latch는 Set과 Reset 입력을 이용하여 1비트 상태를 저장하는 가장 기본적인 기억 구조입니다.

SRQ
00이전 상태 유지
101 저장
010 저장
11금지 상태

기억이 가능한 이유

출력 Q→Feedback→내부 입력→상태 유지

출력이 내부 입력으로 다시 연결되는 Feedback 구조 때문에 입력이 사라진 뒤에도 이전 상태를 유지할 수 있습니다.

검증 메모: 아래 교육용 Behavioral 코드에서는 if (s) ... else if (r) 우선순위를 사용하므로 S=1, R=1일 때 이론적인 SR Latch의 금지 상태를 그대로 모델링하지 않습니다. 진리표의 금지 상태 개념과 교육용 비교 코드는 구분해서 봐야 합니다.
STEP 04

4. 조합회로와 기억회로 비교

원본 실습은 하나의 모듈에서 조합 출력 y와 상태 저장 출력 q를 함께 관찰합니다.

module compare_memory(
    input a,
    input s,
    input r,
    output y,
    output reg q
);

assign y = a;

always @(*) begin
    if (s)
        q = 1'b1;
    else if (r)
        q = 1'b0;
    // s=0, r=0이면 이전 q 유지
end

endmodule
출력동작
ya가 변하면 즉시 함께 변함
qSet/Reset으로 저장한 값을 입력이 사라진 뒤에도 유지
STEP 05

5. Testbench로 상태 유지 확인

initial begin
    a = 1'b0;
    s = 1'b0;
    r = 1'b0;
    #10;

    a = 1'b1; #10;
    a = 1'b0; #10;

    s = 1'b1;
    r = 1'b0;
    #10;            // q = 1 저장

    s = 1'b0;
    r = 1'b0;
    #10;            // q = 1 유지

    s = 1'b0;
    r = 1'b1;
    #10;            // q = 0 저장

    s = 1'b0;
    r = 1'b0;
    #10;            // q = 0 유지

    $finish;
end
초기 s=0, r=0에서는 저장된 이전 상태가 아직 없으므로 Simulation의 q가 X로 보일 수 있습니다. Set 또는 Reset을 수행한 뒤부터 상태 유지가 명확해집니다.
STEP 06

6. Latch의 Level Sensitive 특성

Latch는 특정 순간만 입력을 보는 것이 아니라 Enable이 활성화된 구간 전체에서 입력 변화에 반응합니다.

Enable = 1 → 입력 변화가 출력에 계속 반영
Enable = 0 → 이전 상태 유지

문제점

  • Enable 구간 중 입력이 흔들리면 출력도 계속 변할 수 있음
  • 짧은 Glitch가 들어오면 원하지 않는 값이 저장될 수 있음
  • 입력 변경 시점, Enable 종료 시점, 회로 지연시간의 영향이 커짐

이 때문에 현대 FPGA RTL에서는 의도하지 않은 Latch가 생성되지 않도록 주의합니다.

STEP 07

7. Inferred Latch — 교육용 나쁜 예제

조합논리를 작성하려고 했지만 모든 조건에서 출력값을 대입하지 않으면 합성기가 이전 값을 유지해야 한다고 판단하여 Latch를 만들 수 있습니다.

module bad_latch(
    input en,
    input d,
    output reg q
);

always @(*) begin
    if (en)
        q = d;
    // else가 없으므로 en=0일 때 q 유지
end

endmodule
else 없음 → en=0일 때 q의 새 값 정의 없음 → 이전 q 유지 필요 → Latch 추론 가능
주의: 이 코드는 Latch가 어떻게 의도치 않게 생성되는지 확인하기 위한 교육용 예제입니다. 정상적인 조합회로 코딩에서는 모든 조건에서 출력이 결정되도록 작성해야 합니다.

핵심 정리

  • 조합회로는 현재 입력만 사용하지만 순차회로는 이전 상태를 기억합니다.
  • SR Latch는 Feedback 구조를 이용하여 1비트 상태를 저장합니다.
  • S=0, R=0에서는 이전 상태를 유지합니다.
  • Latch는 Level Sensitive 회로이므로 Enable이 활성화된 동안 입력 변화에 계속 반응합니다.
  • 조합논리 always @(*)에서 모든 조건에 출력값을 대입하지 않으면 Inferred Latch가 생길 수 있습니다.
  • FPGA RTL에서는 의도치 않은 Latch 생성을 피하고, 다음 단계에서 Edge Triggered Flip-Flop 구조로 확장합니다.
