Counter Step 1 · Tick · BCD · FND RTL 실습

기준 Clock을 직접 나누어 새 Clock을 만드는 대신, 일정 주기마다 1 Clock 폭의 Tick을 생성하고 그 Tick을 Enable로 사용해 Counter를 증가시키는 동기식 설계 흐름을 익힙니다.

Counter Tick Enable 1Hz Blink Mod-10 BCD Basys3 FND

Tick

목표 시간마다 단 1 Clock 동안만 1이 되는 Enable 신호입니다.

Blink

0.5초마다 반전되어 전체 주기 1초, Duty 50%의 점멸 신호를 만듭니다.

핵심 원칙

tick_1hz를 새 Clock으로 쓰지 않고 100MHz Clock의 Enable로 사용합니다.

STEP 02

2. 짧은 Tick 생성

먼저 원리를 쉽게 확인하기 위해 5 Clock마다 1 Clock 폭의 Tick을 생성합니다.

clk → div_count 0→1→2→3→4 → tick=1 → div_count=0 
if (div_count == 3'd4) begin
    div_count <= 3'd0;
    tick <= 1'b1;
end
else begin
    div_count <= div_count + 1'b1;
    tick <= 1'b0;
end
신호확인 내용
div_count0 → 1 → 2 → 3 → 4 → 0 반복
tick5 Clock마다 1 Clock 동안만 1

STEP 04

4. 1자리 Up Counter

tick=1인 Clock Edge에서만 0~9 Count를 증가시킵니다.

always @(posedge clk) begin
    if (reset)
        count <= 4'd0;
    else if (tick) begin
        if (count == 4'd9)
            count <= 4'd0;
        else
            count <= count + 1'b1;
    end
end
0 → 1 → 2 → ... → 8 → 9 → 0 → 반복
STEP 05

5. Reset + Enable Counter

if (enable && tick) begin
    if (count == 4'd9)
        count <= 4'd0;
    else
        count <= count + 1'b1;
end
resetenabletick동작

STEP 06

6. Mod-10 BCD Counter와 Carry

BCD(Binary Coded Decimal, 2진화 10진수) Counter는 4bit를 사용하지만 유효 상태는 0~9만 사용합니다. 

carry <= 1'b0;

if (enable && tick) begin
    if (bcd == 4'd9) begin
        bcd <= 4'd0;
        carry <= 1'b1;
    end
    else begin
        bcd <= bcd + 1'b1;
    end
end
BCD 9 → 0으로 복귀하는 순간 → carry 1 Clock 발생 → 다음 자리 증가에 사용
STEP 07

7. Basys3 FND Counter 종합

100MHz→ Tick Generator→ 0~9 Counter→ 7-Segment Decoder
Basys3 자원역할
btnUReset
sw[0]Counter Enable
led[3:0]현재 Count 확인
led[15]blink_1hz 확인
seg[6:0]0~9 숫자 표시
an[3:0]오른쪽 1자리 FND 선택
dp1Hz Duty 50% 점멸
 
assign dp = ~blink_1hz;
assign led[3:0] = count;
assign led[15] = blink_1hz;

always @(*) begin
    an = 4'b1110;

    case (count)
        4'd0: seg = 7'b1000000;
        ...
        4'd9: seg = 7'b0010000;
        default: seg = 7'b1111111;
    endcase
end

핵심 정리

  • Counter는 기준 Clock의 횟수를 저장하고, Compare를 통해 목표 시점을 검출합니다.
  • Tick은 1 Clock 폭의 Enable 신호이며 새로운 Clock으로 사용하지 않습니다.
  • tick_1hz는 Counter 증가에, blink_1hz는 LED·DP 점멸에 사용합니다.
  • 100MHz에서 0.5초는 50,000,000 Clock이므로 비교값은 49,999,999입니다.
  • Mod-10 BCD Counter는 0~9를 반복하고 9→0 전환 시 Carry를 발생시킵니다.
  • Basys3 종합 실습에서는 Count·FND·DP를 하나의 100MHz Clock Domain 안에서 동작시킵니다.
