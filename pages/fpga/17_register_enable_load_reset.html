8bit Register · Enable · Load · Reset RTL 실습

D Flip-Flop 1개가 1bit를 저장한다면 Register는 여러 bit를 동시에 저장합니다. 기본 8bit Register에서 시작해 Enable, Load, Hold, Reset 기능으로 확장합니다.

Register 8bit Enable Load / Hold Reset

기본 구조

D[7:0] → Register → Q[7:0], Clock 상승 Edge에서 8bit를 동시에 저장합니다.

기능 확장

Enable·Load로 저장 여부를 제어하고 Reset/Clear로 초기 상태를 만듭니다.

STEP 01

1. Register란?

Register는 여러 개의 Flip-Flop을 묶어 여러 bit 데이터를 동시에 저장하는 순차회로입니다.

구분저장 크기
Flip-Flop1bit
Register여러 bit
8bit Register8bit 데이터를 동시에 저장
D[7:0] → Register → Q[7:0]
Clock 상승 Edge 순간에 입력 8bit를 저장

CPU의 명령어·데이터 저장, UART 송수신 데이터, Counter 상태, FSM 상태, FPGA 중간 데이터 저장 등에 사용됩니다.

STEP 02

2. 기본 8bit Register

module register8(
    input clk,
    input [7:0] d,
    output reg [7:0] q
);

always @(posedge clk) begin
    q <= d;
end

endmodule
Clock 상태Register 동작
상승 Edged[7:0]를 q[7:0]에 저장
나머지 구간이전 q 유지
8bit라고 해서 별도의 특별한 저장 원리가 생기는 것이 아니라, D Flip-Flop 저장 동작을 8bit Vector로 확장한 구조로 이해하면 됩니다.

initial begin
    clk = 0;

initial begin
    d = 8'h00;

    #7;  d = 8'hAA;

end
#5마다 Clock 반전 → Period 10ns → 100MHz

d가 바뀌는 순간이 아니라 다음 Clock 상승 Edge에서 q가 새 값으로 바뀌는지 Waveform에서 확인합니다.

STEP 04

4. Enable Register와 Hold

Enable은 저장 동작의 허용 여부를 결정합니다. 원본 자료에서는 TTL-IC 74377과 연결해 설명합니다.

always @(posedge clk) begin
    if (en)
        q <= d;
end
enClock 상승 Edge에서의 동작
1새로운 d 저장
0이전 q 유지 — Hold
en=1 → Load new data
en=0 → Hold previous data
STEP 05

5. Load Register

always @(posedge clk) begin
    if (load)
        q <= d;
end

이 실습의 load는 1일 때 새 데이터를 저장하고 0일 때 이전 값을 유지합니다. 단순 Register 실습에서는 Enable과 거의 같은 제어 형태로 사용됩니다.

load동작
1Parallel 데이터 저장
0이전 상태 유지
STEP 06

6. Enable과 Load를 어떻게 구분하는가?

단순한 저장 회로에서는 두 신호 모두 “Clock Edge에서 저장 여부를 결정”하는 형태로 작성될 수 있습니다. 그러나 기능이 복합화되면 의미가 달라질 수 있습니다.

원본의 74LS194 예

always @(posedge clk) begin
    case ({s1, s0})
        2'b00: q <= q;                     // Hold
        2'b01: q <= {serial_in, q[3:1]};   // Shift Right
        2'b10: q <= {q[2:0], serial_in};   // Shift Left
        2'b11: q <= d;                     // Parallel Load
    endcase
end
여기서 Parallel Load는 단순한 “저장 허용”이 아니라 여러 동작 중 병렬 입력 데이터를 선택해 저장하는 하나의 동작 모드입니다. 다음 Shift Register 챕터에서 이 구조를 더 확장합니다.
STEP 07

7. Reset / Clear Register

always @(posedge clk) begin
    if (reset)
        q <= 8'h00;
    else
        q <= d;
end

위 코드는 동기식 Reset 구조입니다. reset=1이어도 실제 상태 변경은 Clock 상승 Edge에서 일어납니다.

resetClock 상승 Edge에서 q
18'h00으로 초기화
0d 저장
Reset/Clear는 FSM 초기 상태, Counter 초기값, CPU 및 각종 상태 Register 초기화에 사용됩니다.
STEP 08

8. FPGA 내부 관점 — Register + 조합논리

원본 자료는 FPGA 구조를 다음 관점으로 정리합니다.

Register + Combinational Logic → Synchronous Digital System

조합논리가 다음 값을 계산하고 Register가 Clock Edge에서 그 값을 저장하는 구조가 반복되면서 Counter, FSM, UART, CPU Datapath 같은 더 큰 디지털 시스템으로 확장됩니다.

검증 포인트: Reset이 없는 기본 Register는 Simulation 시작 직후 첫 유효한 Clock Edge 이전까지 q가 미정 상태로 보일 수 있습니다. 실제 출력처럼 임의의 초기값을 가정하지 말고 Waveform에서 상태를 확인합니다.

핵심 정리

  • Register는 여러 Flip-Flop을 묶어 여러 bit를 동시에 저장하는 순차회로입니다.
  • 기본 Register는 Clock 상승 Edge에서 d를 q에 저장합니다.
  • Enable 또는 Load가 비활성화되면 이전 값을 유지하는 Hold 동작이 가능합니다.
  • Reset/Clear는 Register를 정해진 초기값으로 되돌립니다.
  • FPGA 디지털 시스템은 크게 Register와 조합논리의 반복 구조로 이해할 수 있습니다.
  • Register에 데이터 이동 기능을 추가하면 다음 단계인 Shift Register로 확장됩니다.
