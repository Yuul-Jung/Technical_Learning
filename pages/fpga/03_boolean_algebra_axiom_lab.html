부울대수 공리 FPGA 실습

Basys3의 SW0와 LED0~LED3를 이용하여 부울대수의 기본 공리를 Verilog HDL로 구현하고, 입력 변화에 따른 실제 FPGA 출력을 확인합니다.

Boolean Algebra Verilog HDL Basys3 Vivado 2024.2

입력

SW0의 1비트 입력값 X를 사용합니다.

검증 대상

X·1=X, X+0=X, X·0=0, X+1=1을 LED로 확인합니다.

완료 기준

SW0=0과 SW0=1에서 LED0~LED3의 결과가 진리표와 일치하면 완료입니다.

STEP 01

1. 부울대수 공리 이해

하나의 입력 X를 SW0로 두고, 네 개의 기본 공리를 LED0~LED3에 각각 연결합니다.

LED논리식의미
LED0X · 1 = XAND Identity
LED1X + 0 = XOR Identity
LED2X · 0 = 0Null Law
LED3X + 1 = 1Dominance Law
SW0(X) → 4개의 Boolean 연산 → LED0 · LED1 · LED2 · LED3

STEP 03

3. Verilog HDL 작성

파일명은 top.v로 작성합니다.

module top(

    input  wire [0:0] sw,
    output wire [3:0] led

);

assign led[0] = sw[0] & 1'b1;
assign led[1] = sw[0] | 1'b0;
assign led[2] = sw[0] & 1'b0;
assign led[3] = sw[0] | 1'b1;

endmodule

코드 풀이 — 각 식이 의미하는 것

코드동작
&AND 연산
|OR 연산
1'b11비트 논리값 1
1'b01비트 논리값 0
led[0] ← X·1    |    led[1] ← X+0    |    led[2] ← X·0    |    led[3] ← X+1

STEP 07

7. 실험 결과 확인

SW0LED0LED1LED2LED3
00001
11101

LED0 — X · 1 = X

입력값이 그대로 출력됩니다.

LED1 — X + 0 = X

입력값이 그대로 출력됩니다.

LED2 — X · 0 = 0

입력과 관계없이 항상 0입니다.

LED3 — X + 1 = 1

입력과 관계없이 항상 1입니다.

실제 보드에서는 SW0를 0과 1로 각각 변경하면서 LED0~LED3의 상태가 위 진리표와 일치하는지 확인합니다.

확인 문제

  1. 왜 X · 0은 항상 0이 되는가?
  2. 왜 X + 1은 항상 1이 되는가?
  3. 부울대수 공리가 실제 FPGA 하드웨어에서 어떤 신호 관계로 구현되는가?
STEP 08

8. 모듈명 작성 규칙

Verilog에서 module은 하나의 회로 블록을 정의합니다.

module top(
    input  wire sw,
    output wire led
);

endmodule
규칙예
영문·숫자·언더바 사용uart_tx, counter8
숫자로 시작하지 않음adder_4bit
공백 사용 금지led_controller
대소문자 구분top과 Top은 다른 이름
파일명과 모듈명 일치 권장uart_tx.v ↔ module uart_tx
실습에서는 top.v와 module top처럼 파일명과 모듈명을 맞추는 방식이 가장 단순합니다.

핵심 정리

  • 부울대수 공리를 Verilog의 AND·OR 연산으로 직접 구현했습니다.
  • 하나의 입력 SW0로 네 개의 논리식을 동시에 계산하고 LED0~LED3에서 결과를 확인합니다.
  • X·1=X과 X+0=X는 입력을 그대로 전달합니다.
  • X·0=0은 항상 0, X+1=1은 항상 1입니다.
  • 파일명과 모듈명을 일치시키는 규칙은 이후 계층적 RTL 설계에서도 계속 적용합니다.
