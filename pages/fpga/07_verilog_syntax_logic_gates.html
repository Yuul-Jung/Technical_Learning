SECTION 03

3. Port 선언

Port는 Module과 외부 회로를 연결하는 신호 통로입니다.

input  wire sw0;
input  wire sw1;
output wire led0;
보드 Switch → input Port → RTL Logic → output Port → LED

Top Module에서는 이러한 Port 이름이 XDC의 get_ports 이름과 직접 연결됩니다.

여러 비트 Vector

표현비트 수사용 예
[1:0] sw2비트sw[0], sw[1]
[6:0] led7비트led[0] ~ led[6]
SECTION 05

5. wire와 assign

wire는 회로 블록 사이의 연결 신호를 표현하고, assign은 조합논리의 연속 할당에 사용합니다.

output wire y;
assign y = a & b;
입력 a, b가 변함 → AND 결과 즉시 계산 → y 신호 갱신
이 단계에서는 Clock이나 상태 저장이 없는 조합논리를 다루므로 assign 표현이 직관적입니다.
SECTION 06

6. 로직게이트와 Verilog 연산자

GateVerilog예
NOT~assign y = ~a;
AND&assign y = a & b;
OR|assign y = a | b;
XOR^assign y = a ^ b;
NANDAND + NOTassign y = ~(a & b);
NOROR + NOTassign y = ~(a | b);

Verilog에서는 이 연산식이 단순 계산 결과가 아니라 합성 후 FPGA 내부 논리 자원으로 구현됩니다.

SECTION 07

7. 통합 문법 예제

다음 코드는 문법을 한 번에 확인하기 위한 보완 예제이며, 원본 슬라이드에서 직접 추출한 코드는 아닙니다.

module logic_syntax_demo(
    input  wire [1:0] sw,
    output wire [5:0] led
);

assign led[0] = ~sw[0];
assign led[1] =  sw[0] & sw[1];
assign led[2] =  sw[0] | sw[1];
assign led[3] = ~(sw[0] & sw[1]);
assign led[4] = ~(sw[0] | sw[1]);
assign led[5] =  sw[0] ^ sw[1];

endmodule
Vector 입력 선언 → Bit Select → 논리 연산 → Vector 출력
SECTION 08

8. Vivado에서 확인할 것

  1. Design Sources에 Verilog 파일 추가
  2. Top Module 지정
  3. XDC에서 SW·LED 포트 연결
  4. Elaborated Design에서 Port와 논리 연결 확인
  5. Run Synthesis → Run Implementation → Generate Bitstream
  6. Basys3에 Program Device 후 SW 입력에 따른 LED 결과 확인
중요: Verilog는 대소문자를 구분하므로 Module 이름, Port 이름, XDC의 get_ports 이름을 동일하게 유지합니다.

핵심 정리

  • module은 회로 블록을 정의하고 Port는 외부 회로와 신호를 연결합니다.
  • Scalar는 1비트, Vector는 여러 비트 신호를 묶어 표현합니다.
  • wire와 assign은 기본 조합논리 연결을 표현할 때 사용합니다.
  • ~, &, |, ^ 연산자는 NOT, AND, OR, XOR Gate와 직접 대응합니다.
  • 문법을 외우는 것보다 SW → 논리식 → LED로 이어지는 실제 회로 흐름과 연결해서 이해합니다.
