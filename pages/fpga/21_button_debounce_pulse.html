STEP 01

1. 기계식 버튼의 Bounce

버튼을 한 번 눌러도 접점이 즉시 깨끗한 0→1로 바뀌지 않고, 짧은 시간 동안 0과 1이 반복될 수 있습니다. 

btn_in
0  1  0  1  0  1  1  1  1 ...
   └──── Bounce 구간 ────┘
버튼 1회 입력 → 여러 번의 0/1 전환처럼 보일 수 있음

따라서 버튼 입력을 Counter 증가, Start/Stop, FSM 상태 전이 등에 바로 사용하면 한 번 누른 동작이 여러 번 실행되는 것처럼 보일 수 있습니다.

STEP 02

2. 2-FF Synchronizer — 비동기 입력 동기화

always @(posedge clk) begin
    if (reset) begin
        btn_sync_0 <= 1'b0;
        btn_sync_1 <= 1'b0;
    end
    else begin
        btn_sync_0 <= btn_in;
        btn_sync_1 <= btn_sync_0;
    end
end
btn_in → btn_sync_0 → btn_sync_1
중요: 2-FF Synchronizer(동기화기)는 Bounce를 제거하는 회로가 아닙니다. 외부 비동기 입력을 시스템 Clock 기준 신호로 정리하고 메타안정성 전파 위험을 줄이는 역할입니다.

따라서 2-FF를 지난 btn_sync_1에도 버튼 접점의 Bounce 자체는 남아 있을 수 있으며, 별도의 Debounce 단계가 필요합니다.

STEP 03

3. Debounce Counter — 안정 시간 확인

localparam integer DEBOUNCE_COUNT =
    (CLK_HZ / 1000) * DEBOUNCE_MS;

Basys3 100MHz · 20ms 기준

100,000,000 / 1000 → 100,000 Clock/ms
100,000 × 20ms → DEBOUNCE_COUNT = 2,000,000

btn_sync_1이 현재 안정 상태 btn_stable과 다르면 Counter를 증가시키고, 중간에 다시 기존 상태로 돌아오면 Counter를 0으로 초기화합니다. 

if (btn_sync_1 == btn_stable) begin
    count <= 32'd0;
end
else begin
    if (count >= DEBOUNCE_COUNT - 1) begin
        btn_stable <= btn_sync_1;
        count <= 32'd0;
    end
    else begin
        count <= count + 1'b1;
    end
end
STEP 04

4. btn_stable — 안정 상태 확정

입력 변화가 설정된 Debounce 시간 동안 연속으로 유지되면 그때서야 btn_stable을 새로운 버튼 상태로 갱신합니다.

조건동작
btn_sync_1 == btn_stable변화 없음 → Counter 0
두 값이 다름새 상태 후보 → Counter 증가
중간에 원래 상태 복귀Bounce로 판단 → Counter 0
DEBOUNCE_COUNT 도달새 안정 상태로 인정
STEP 05

5. Rising Edge 검출과 1-Clock Pulse

이전 Clock의 안정 상태를 btn_stable_d에 저장합니다.

always @(posedge clk) begin
    if (reset)
        btn_stable_d <= 1'b0;
    else
        btn_stable_d <= btn_stable;
end

현재 상태와 이전 상태를 비교하면 안정된 0→1 변화 순간만 검출할 수 있습니다.

assign pulse_out = btn_stable & ~btn_stable_d;
btn_stable 0→1
+ 이전 상태 btn_stable_d=0
→ pulse_out=1
→ 다음 Clock에는 다시 0
STEP 06

6. 전체 RTL 구조

module button_debounce_pulse #(
    parameter CLK_HZ      = 100_000_000,
    parameter DEBOUNCE_MS = 20
)(
    input  wire clk,
    input  wire reset,
    input  wire btn_in,
    output wire pulse_out
);
1단계

STEP 07

7. Timing 흐름 해석

원본 자료의 교육용 Timing 예에서는 실제 20ms 대신 DEBOUNCE_COUNT=8처럼 짧게 표현합니다.

시간 →
btn_in        0 1 0 1 0 1 1 1 1 1 1 1 ...
btn_sync_0    0 0 1 0 1 0 1 1 1 1 1 1 ...
btn_sync_1    0 0 0 1 0 1 0 1 1 1 1 1 ...

앞선 Counter와 Stopwatch에서는 버튼을 제어 입력으로 사용했습니다. 이번 단계는 그 버튼 입력 자체를 FPGA 내부에서 안정적으로 사용할 수 있는 형태로 정리하는 회로입니다.

원본의 회로 이미지는 임시 서명 URL이므로 GitHub Pages에 직접 연결하지 않았습니다. 대신 원본 Timing 설명과 실제 신호명을 그대로 사용해 텍스트 기반으로 구조를 정리했습니다.

핵심 정리

  • 기계식 버튼은 한 번 눌러도 짧은 시간 동안 0과 1이 반복되는 Bounce가 발생할 수 있습니다.
  • 2-FF Synchronizer는 Bounce 제거가 아니라 비동기 입력 동기화와 메타안정성 전파 위험 완화를 위한 단계입니다.
  • Debounce Counter는 새로운 입력 상태가 설정 시간 동안 유지될 때만 btn_stable을 갱신합니다.
  • Basys3 100MHz, 20ms 기준 DEBOUNCE_COUNT는 2,000,000입니다.
  • btn_stable & ~btn_stable_d로 안정된 상승 Edge에서 1-Clock Pulse를 생성합니다.
  • 이 Pulse를 Counter, Stopwatch, FSM 등의 버튼 이벤트 입력으로 사용할 수 있습니다.
