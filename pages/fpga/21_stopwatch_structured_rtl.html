STEP 02

2. 0.01초 Tick 생성

100MHz → 1 Clock = 10ns
0.01초 ÷ 10ns → 1,000,000 Clock
Counter 0부터 시작 → 비교값 999,999 
if (count_div == 20'd999_999) begin
    count_div <= 20'd0;
    tick <= 1'b1;
end
else begin
    count_div <= count_div + 1'b1;
end

Tick은 0.01초마다 1 Clock 동안만 HIGH가 됩니다. 원본 구조에서는 Stopwatch가 정지하면 count_div도 0으로 되돌려 다음 Start 시 시간 기준을 다시 시작합니다.

if (enable) begin
    digit0 <= carry0 ? 4'd0 : digit0 + 1'b1;

    if (carry0)
        digit1 <= (digit1 == 4'd9) ? 4'd0 :
                  digit1 + 1'b1;

    if (carry1)
        digit2 <= (digit2 == 4'd9) ? 4'd0 :
                  digit2 + 1'b1;

    if (carry2)
        digit3 <= (digit3 == 4'd9) ? 4'd0 :
                  digit3 + 1'b1;
end
STEP 04

4. Start / Stop 상태 저장

always @(posedge clk) begin
    if (reset)
        running <= 1'b0;
    else begin
        if (start)
            running <= 1'b1;
        else if (stop)
            running <= 1'b0;
    end
end
Start → running=1 → Tick 생성 허용 → Count 진행
Stop → running=0 → Tick 정지 → Count 유지
코드 구조상 Start와 Stop이 동시에 1이면 if (start)가 먼저 평가되므로 Start가 우선합니다.
STEP 05

5. FND Scan Counter

scan_div <= scan_div + 1'b1;
digit_sel <= scan_div[15:14];
scan_div[15:14] → 00 → 01 → 10 → 11 → digit0 → digit1 → digit2 → digit3 반복

Stopwatch Count 속도와 FND Scan 속도는 서로 다른 목적을 갖습니다. Count는 0.01초 단위이고, FND Scan은 빠르게 4자리를 반복 선택합니다.

STEP 06

6. FND MUX · Decimal Point · Decoder

선택된 Digit을 current_digit으로 보내고, 같은 Decoder 하나를 공유합니다.

case (digit_sel)
    2'd0: begin
        current_digit = digit0;
        an = 4'b1110;
        dp = 1'b1;
    end

    2'd1: begin
        current_digit = digit1;
        an = 4'b1101;
        dp = 1'b1;
    end

    2'd2: begin
        current_digit = digit2;
        an = 4'b1011;
        dp = 1'b0;
    end

    2'd3: begin
        current_digit = digit3;
        an = 4'b0111;
        dp = 1'b1;
    end
endcase
digit3 digit2 . digit1 digit0 → digit2가 선택될 때 DP ON → 시각적으로 XX.XX 형태

핵심 정리

  • 0.01초 Tick은 100MHz Clock 1,000,000개를 세어 생성합니다.
  • Start/Stop은 running 상태를 저장하여 Stopwatch 실행 여부를 제어합니다.
  • 4자리 BCD Counter는 0.01초 → 0.1초 → 1초 → 10초 순서로 자리 올림합니다.
  • FND Scan·MUX·Decoder는 Counter와 분리된 독립 모듈로 구성됩니다.
  • Top Module은 각 모듈을 연결해 하나의 Basys3 Stopwatch 시스템으로 통합합니다.
  • Counter Step 1·2의 기능을 재사용 가능한 구조화 RTL로 확장한 단계입니다.
