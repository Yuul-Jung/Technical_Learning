STEP 01

1. Latch에서 Flip-Flop으로

Latch는 기억 기능을 제공하지만 Enable이 활성화된 동안 입력 변화에 계속 반응합니다. 반면 Flip-Flop은 Clock의 특정 순간에만 입력을 저장합니다.

STEP 02

2. Positive Edge와 Negative Edge

EdgeClock 변화동작
Positive Edge0 → 1상승 순간 D를 Q에 저장
Negative Edge1 → 0하강 순간 D를 Q에 저장
Clock Level 전체를 보는 것이 아니라 → 변화하는 순간을 기준으로 저장합니다.
STEP 03

3. D Flip-Flop 기본 동작

ClockDQ
상승 Edge 없음0이전 상태 유지
상승 Edge 없음1이전 상태 유지
상승 Edge 발생00 저장
상승 Edge 발생11 저장
module d_ff(
    input clk,
    input d,
    output reg q
);

always @(posedge clk) begin
    q <= d;
end

endmodule

D가 중간에 여러 번 변해도 Q는 상승 Edge가 발생하는 순간의 D 값만 저장합니다.

STEP 04

4. posedge와 Non-blocking Assignment

Clock Edge 지정

always @(posedge clk)

posedge는 Clock이 0에서 1로 변하는 상승 Edge를 의미합니다.

순차회로 대입

q <= d;

Flip-Flop과 Register 같은 Clock 기반 순차회로에서는 Non-blocking Assignment(논블로킹 대입) <=를 기본으로 사용합니다.

작성 기준: q = d;도 문법적으로 사용할 수 있는 경우가 있지만, Clock 기반 순차회로의 상태 갱신에는 <=를 사용하는 것이 기본 규칙입니다.
STEP 05

5. D Flip-Flop Testbench

initial begin
    clk = 1'b0;
    forever #5 clk = ~clk;  // 10ns Clock
end

initial begin
    d = 1'b0;
    #7;

    d = 1'b1; #3;
    d = 1'b0; #4;
    d = 1'b1; #6;

    d = 1'b0; #10;
    d = 1'b1; #10;
    d = 1'b0; #10;

    $finish;
end

Clock 계산

#5마다 Clock 반전 → HIGH 5 ns + LOW 5 ns → Clock Period 10 ns → 100 MHz

D는 Clock과 무관한 시점에도 변경됩니다. Waveform에서는 Q가 D를 계속 따라가지 않고 상승 Edge 순간에만 갱신되는지 확인합니다.

STEP 06

6. Reset이 있는 D Flip-Flop

동기 Reset

always @(posedge clk) begin
    if (rst)
        q <= 1'b0;
    else
        q <= d;
end

Synchronous Reset(동기 리셋)은 rst=1이더라도 Clock 상승 Edge에서 Reset이 반영됩니다.

비동기 Reset 구조 비교

always @(posedge clk or posedge rst) begin
    if (rst)
        q <= 1'b0;
    else
        q <= d;
end

Asynchronous Reset(비동기 리셋)은 Clock Edge를 기다리지 않고 Reset 신호가 활성화되면 즉시 Q를 초기화합니다.

구분동기 Reset비동기 Reset
Reset 반영 시점Clock EdgeReset 활성화 즉시
Sensitivity Listposedge clkposedge clk or posedge rst
상태 변화 기준Clock과 정렬Clock과 독립 가능
STEP 07

7. Latch와 Flip-Flop 직접 비교

// Latch
always @(*) begin
    if (en)
        q_latch = d;
end

// D Flip-Flop
always @(posedge clk) begin
    q_ff <= d;
end
입력 변화q_latchq_ff
en=1에서 d 변화즉시 반영상승 Edge까지 유지
en=0에서 d 변화이전 값 유지상승 Edge에서 d 저장
Clock 상승 EdgeClock과 무관D를 Q에 저장
이 비교를 통해 Level Sensitive와 Edge Sensitive의 차이를 Waveform에서 직접 확인할 수 있습니다.

핵심 정리

  • Latch는 Level Sensitive, Flip-Flop은 Edge Sensitive 저장소입니다.
  • D Flip-Flop은 Clock의 특정 Edge 순간의 D 값을 Q에 저장합니다.
  • 상승 Edge 방식은 always @(posedge clk)로 표현합니다.
  • Clock 기반 순차회로의 상태 갱신에는 Non-blocking Assignment <=를 기본으로 사용합니다.
  • 동기 Reset은 Clock Edge에서, 비동기 Reset은 Reset 활성화 즉시 상태를 초기화할 수 있습니다.
  • D Flip-Flop은 이후 Register, Counter, Shift Register, FSM, CPU Datapath의 기본 저장 요소가 됩니다.
