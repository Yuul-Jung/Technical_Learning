74 시리즈 기반 Verilog RTL 설계 가이드

74 시리즈 디지털 회로를 기준으로 Verilog RTL 모듈을 Gate, Combinational, Sequential, Project/Peripheral 계열로 나누고, 파일명·모듈명 규칙과 계층적 프로젝트 구조를 정리합니다.

Digital System Verilog RTL 74 Series FPGA

핵심 관점

Verilog는 프로그램을 순서대로 실행하는 언어가 아니라 하드웨어 회로를 기술하는 HDL입니다.

분류 기준

g_, c_, s_, p_ 접두어로 RTL 모듈의 역할을 구분합니다.

확장 방향

Gate → 조합논리 → 순차논리 → UART/FSM 같은 실제 FPGA 기능으로 확장합니다.

SECTION 01

1. FPGA 설계 철학

Verilog는 일반적인 소프트웨어 프로그램 언어처럼 명령을 순서대로 실행하기 위한 언어가 아닙니다.

Verilog HDL 작성 → 하드웨어 구조 기술 → FPGA 내부 회로 구현
관점의미
Software 관점명령을 순서대로 실행
Verilog HDL 관점동시에 존재하는 하드웨어 회로와 신호 관계를 기술
이 장의 기준은 “코드를 실행한다”보다 “코드로 회로를 만든다”에 두고 있습니다.

SECTION 03

3. g_ : Gate 계열

Gate 계열은 가장 기본적인 논리 연산을 담당하며, 출력은 현재 입력값으로 결정됩니다.

파일명기능
g_not_7404.vNOT Gate
g_buffer_7407.vBuffer
g_nand_7400.vNAND Gate
g_nor_7402.vNOR Gate
g_and_7408.vAND Gate
g_or_7432.vOR Gate
g_xor_7486.vXOR Gate

Gate 예제

module g_and_7408(
    input  a,
    input  b,
    output y
);

assign y = a & b;

endmodule

핵심 개념은 Boolean Algebra, Truth Table, DeMorgan Law, Universal Gate, assign 문입니다.

SECTION 04

4. c_ : Combinational 계열

조합논리 회로는 기억 기능이 없으며 출력이 현재 입력 상태에만 의존합니다.

파일명기능
c_mux2_74157.v2:1 MUX
c_mux8_74151.v8:1 MUX
c_decoder2_74139.v2-to-4 Decoder
c_decoder3_74138.v3-to-8 Decoder
c_decoder4_74154.v4-to-16 Decoder
c_encoder8_74148.vPriority Encoder
c_comparator_7485.vComparator
c_adder4_74283.v4-bit Adder
c_alu_74181.vALU
c_sevenseg_7447.v7-Segment Decoder

Decoder

Decoder는 하나의 대상을 선택하는 회로로 주소 선택, 메모리 선택, 장치 선택, FSM 상태 선택 등에 연결됩니다.

MUX

MUX는 여러 입력 중 하나를 선택하여 전달하는 회로입니다.

ALU

ALU는 덧셈, 뺄셈, AND, OR, XOR, 비교 등의 연산을 수행하는 조합논리 구조입니다.

SECTION 05

5. s_ : Sequential 계열

순차논리 회로는 현재 입력뿐 아니라 이전 상태를 함께 사용합니다. 즉, 기억 기능이 존재합니다.

현재 입력 + 이전 상태 → 현재 출력 · 다음 상태
파일명기능
s_dff_7474.vD Flip-Flop
s_latch_7475.vLatch
s_counter_74161.vSynchronous Counter
s_counter_7490.vDecade Counter
s_shift_74164.vShift Register
s_shift_74194.vUniversal Shift Register
s_register_74173.vRegister

Sequential 예제

module s_dff_7474(
    input  clk,
    input  d,
    output reg q
);

always @(posedge clk)
begin
    q <= d;
end

endmodule

핵심 개념은 Clock, Reset, Flip-Flop, Register, Counter, Shift Register, State, Timing, always 블록, Non-blocking Assignment입니다.

Counter

Counter는 상태가 계속 변화하는 순차회로이며 Timer, Frequency Divider, Digital Clock, FSM 등에 활용됩니다.

Shift Register

Shift Register는 데이터를 한 비트씩 이동시키며 UART, SPI, Serial Communication과 연결됩니다.

SECTION 07

7. UART와 FSM으로 확장

UART 구조

UART
├─ UART TX
├─ UART RX
├─ Baud Generator
└─ FSM

FSM

FSM(Finite State Machine)은 순차논리와 조합논리를 결합한 제어 구조입니다.

순차논리 + 조합논리 → FSM Controller

활용 예로 UART, 신호등, 자판기, CPU Control, 통신 제어가 제시됩니다.

SECTION 09

9. Verilog 코딩 스타일 규칙

파일명과 모듈명은 동일하게 작성

g_and_7408.v

module g_and_7408(
    ...
);

포트는 읽기 쉽게 정렬

module g_and_7408(
    input  a,
    input  b,
    output y
);

간단한 조합논리는 assign으로 표현

assign y = a & b;
원본 자료에서는 이 장에서 기본 규칙을 제시하고, 추가 규칙은 별도로 확장하는 방향으로 구성되어 있습니다.

핵심 정리

  • Verilog는 하드웨어 회로를 설명하는 HDL로 이해합니다.
  • g_ → c_ → s_ → p_ 순서로 회로의 복잡도가 확장됩니다.
  • 조합논리는 현재 입력에 의존하고, 순차논리는 현재 입력과 이전 상태에 의존합니다.
  • 74 시리즈 회로를 기준으로 모듈을 분류하면 디지털 회로와 RTL 구조를 연결해서 이해하기 쉽습니다.
  • 파일명과 모듈명을 맞추고 역할별 폴더를 분리하면 이후 UART, FSM, 주변장치 설계로 확장하기 쉽습니다.
