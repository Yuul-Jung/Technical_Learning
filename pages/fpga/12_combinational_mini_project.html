2. Basys3 입출력과 Seven Segment 기준

Basys3의 4자리 Seven Segment는 common-anode 구조이며 자리 선택과 Segment 신호가 active-low로 동작합니다.

AN[3:0] : 자리 선택 → 0일 때 ON
CA~CG   : Segment 선택 → 0일 때 ON
DP      : Dot Point → 0일 때 ON

조합회로 기본 과제에서는 오른쪽 한 자리만 사용합니다.

assign an = 4'b1110;
4자리 전체를 빠르게 스캔하는 방식은 Clock과 순차회로가 필요하므로 이후 Sequential Logic 단계에서 본격적으로 다룹니다.

STEP 05

5. 대표 예제 — 디지털 비밀번호 잠금장치

4bit Switch 입력이 설정된 비밀번호와 일치하면 LED가 켜지고 Seven Segment에 성공 표시를 출력합니다.

SW[3:0]→PASSWORD 비교→LED+7-Segment
module p_password_lock(
    input [3:0] sw,
    output led,
    output reg [6:0] seg,
    output [3:0] an
);

parameter PASSWORD = 4'b1010;

// 오른쪽 1자리 FND만 사용
assign an = 4'b1110;

// 비밀번호 비교 결과
assign led = (sw == PASSWORD);

always @(*) begin
    if(sw == PASSWORD)
        seg = 7'b1000000; // O 형태
    else
        seg = 7'b0001001; // X 대체 표시: H 형태
end

endmodule

코드 흐름

sw 입력 → PASSWORD와 비교 → 같으면 LED=1 → 성공용 Segment 패턴 출력

module tb_password_lock;

reg [3:0] sw;
wire led;
wire [6:0] seg;

p_password_lock dut(

    .led(led),
    .seg(seg),
    .an(an)

    sw = 4'b0000; #10;

핵심 정리

  • LEVEL 2-C는 개별 조합회로를 실제 Mini Project 형태로 결합하는 단계입니다.
  • 프로젝트는 요구사항 → 시스템 구조 → RTL → Testbench → Waveform → RTL Schematic → FPGA 순으로 진행합니다.

  • Seven Segment의 AN과 Segment 신호는 active-low이며, 기본 과제에서는 오른쪽 한 자리만 사용합니다.
  • 비밀번호 잠금장치는 4bit Comparator 개념을 실제 응용 시스템으로 확장한 예입니다.
