STEP 01

1. Shift Register란?

Shift Register는 여러 Flip-Flop에 저장된 데이터를 Clock 상승 Edge마다 한 비트씩 이동시키는 순차회로입니다.

구분RegisterShift Register
기능저장저장 + 이동
데이터 변화저장값 유지Clock마다 한 bit 이동
구조Flip-Flop 배열Flip-Flop + 이동 논리
Din → FF → FF → FF → FF → Dout
Clock 상승 Edge마다 데이터가 한 단계 이동

대표 종류

종류영문데이터 흐름
SISOSerial In Serial Out직렬 입력 → 직렬 출력
SIPOSerial In Parallel Out직렬 입력 → 병렬 출력
PISOParallel In Serial Out병렬 입력 → 직렬 출력
PIPOParallel In Parallel Out병렬 입력 → 병렬 출력
STEP 02

2. Shift 방향과 Concatenation

Shift Left

q <= {q[2:0], din};

기존 q[2:0]이 상위 bit 방향으로 이동하고, 새로운 din이 q[0] 위치로 들어옵니다.

Shift Right

q <= {din, q[3:1]};

기존 q[3:1]이 하위 bit 방향으로 이동하고, 새로운 din이 q[3] 위치로 들어옵니다.

Concatenation(컨캐터네이션, 비트 연결)은 여러 bit를 하나의 Vector로 묶는 문법입니다. 예를 들어 {q[2:0], din}은 총 4bit입니다.
STEP 03

3. SISO — Serial In Serial Out

module shift_register_siso(
    input clk,
    input din,
    output serial_out,
    output reg [3:0] q
);

assign serial_out = q[3];

always @(posedge clk) begin
    q <= {q[2:0], din};
end

endmodule
din → q[0] → q[1] → q[2] → q[3] → serial_out

원본 실습에서는 SISO 동작을 확인하면서 Waveform 관찰을 위해 내부 상태 q[3:0]도 함께 출력합니다.

STEP 04

4. Left / Right Shift 선택

always @(posedge clk) begin
    if (dir == 1'b0)
        q <= {q[2:0], din}; // Left Shift
    else
        q <= {din, q[3:1]}; // Right Shift
end
dir동작
0Shift Left
1Shift Right

하나의 Register에서도 제어 신호에 따라 데이터 이동 방향을 바꿀 수 있습니다.

STEP 05

5. SIPO — Serial In Parallel Out

module shift_register_sipo(
    input clk,
    input din,
    output reg [3:0] q
);

always @(posedge clk) begin
    q <= {q[2:0], din};
end

endmodule
Serial Input → Clock마다 누적 → q[3:0] Parallel Output

직렬 bit가 Clock마다 Register에 누적되어 병렬 데이터가 됩니다. 원본 자료는 이를 UART 수신부의 기본 구조와 연결합니다.

STEP 06

6. PISO — Parallel In Serial Out

assign serial_out = q[0];   // LSB First 출력

always @(posedge clk) begin
    if (load)
        q <= pdata;
    else
        q <= {1'b0, q[3:1]};
end
Parallel Load → q[3:0] 저장 → 오른쪽 Shift → q[0]에서 Serial Output

원본은 q[0]을 직렬 출력으로 사용하므로 LSB First 방식입니다.

예: pdata = 4'b1011

serial_out
1 → 1 → 0 → 1

원본 자료는 이 구조를 UART 송신부의 기본 구조와 연결합니다.

STEP 07

7. Universal Shift Register

여러 Shift 동작과 Parallel Load를 하나의 Register에 통합합니다.

mode기능RTL 동작
00Holdq <= q
01Serial In Shift{serial_in, q[3:1]}
10Serial Out Shift{1'b0, q[3:1]}
11Parallel Loadq <= pdata
 
always @(posedge clk) begin
    if (reset)
        q <= 4'b0000;
    else begin
        case (mode)
            2'b00: q <= q;
            2'b01: q <= {serial_in, q[3:1]};
            2'b10: q <= {1'b0, q[3:1]};
            2'b11: q <= pdata;
            default: q <= q;
        endcase
    end
end
원본 자료는 Universal Shift Register가 SISO·SIPO·PISO·PIPO 구조를 모두 지원하는 통합 구조로 설명합니다.

실습 주의: 원본에서는 이해를 위해 btnC를 수동 Clock으로 직접 사용합니다. 실제 FPGA 설계에서는 Button Debounce(디바운스)와 Synchronizer(동기화 회로)가 필요합니다.

핵심 정리

  • Shift Register는 Register의 저장 기능에 bit 이동 기능을 추가한 순차회로입니다.
  • Shift Left는 {q[2:0], din}, Shift Right는 {din, q[3:1]} 형태로 표현할 수 있습니다.
  • SISO는 직렬 입력을 직렬 출력으로 전달하며, SIPO는 직렬 데이터를 병렬 데이터로 변환합니다.
  • PISO는 병렬 데이터를 저장한 뒤 Clock마다 직렬로 내보냅니다.
  • Universal Shift Register는 Hold·Serial Shift·Parallel Load를 하나의 회로에 통합합니다.
  • Shift Register는 이후 UART 송수신, SPI, CPU Shift 연산, Delay Line 설계와 직접 연결됩니다.
