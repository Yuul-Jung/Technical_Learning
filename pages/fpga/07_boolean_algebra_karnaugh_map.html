2. Boolean Algebra 기본 정리

이름식의미
IdentityX·1 = X / X+0 = X기본값과 연산하면 원래 값 유지
NullX·0 = 0 / X+1 = 10 또는 1이 결과를 지배
IdempotentX·X = X / X+X = X같은 값의 중복 제거
ComplementX·X' = 0 / X+X' = 1상보 관계
DistributiveXY + XZ = X(Y+Z)공통항 묶기
AbsorptionX + XY = X불필요한 항 제거
F = XY + XY'
  = X(Y + Y')
  = X · 1
  = X

STEP 04

4. DeMorgan 정리

~(A · B) = A' + B'
~(A + B) = A' · B'

원본 실습에서는 이 관계를 이용해 NAND Gate만으로 OR Gate를 구현합니다.

A+B = (A' · B')' → 입력 반전 → NAND → OR 동작
STEP 05

5. NAND Universal Gate

NAND만으로 NOT·AND·OR를 구현할 수 있습니다.

기능NAND 기반 표현
NOT AA NAND A
A AND B(A NAND B) NAND (A NAND B)
A OR B(A NAND A) NAND (B NAND B)
STEP 06

6. SOP 논리식

SOP(Sum of Products, 곱의 합)는 진리표에서 출력이 1인 항을 곱항으로 만든 뒤 OR로 합치는 구조입니다.

출력 1인 행 → Minterm → AND 항 → OR 결합
STEP 07

7. POS 논리식

POS(Product of Sums, 합의 곱)는 합항을 만든 뒤 AND로 결합합니다.

출력 0인 행 → Maxterm → OR 항 → AND 결합
STEP 08

8. Karnaugh Map 간략화

F = A'B'C + AB'C + A'BC + ABC

네 항 모두 C=1인 경우이므로 Karnaugh Map에서 하나의 그룹으로 묶입니다.

간략화 결과 → F = C
구분구조
간략화 전4개의 3변수 곱항 + OR 결합
간략화 후C 입력을 그대로 출력

원본의 kmap_3var_compare_top.v처럼 원래 회로와 F=C 회로를 동시에 구현해 결과를 비교합니다.

핵심 정리

  • Gate Module을 조합하면 Boolean Equation을 실제 계층적 RTL 회로로 구현할 수 있습니다.
  • Boolean Algebra는 같은 동작을 유지하면서 중복 항과 불필요한 Gate를 줄입니다.
  • DeMorgan 정리는 NAND/NOR 기반 설계와 연결됩니다.
  • NAND는 NOT·AND·OR를 모두 만들 수 있는 Universal Gate입니다.
  • SOP는 곱항의 합, POS는 합항의 곱 형태입니다.
  • Karnaugh Map은 인접항을 묶어 논리식을 시각적으로 간략화합니다.
  • F = A'B'C + AB'C + A'BC + ABC는 F = C로 줄어듭니다.
