24시간 디지털 시계 · HH:MM RTL 실습

100MHz 기준 Clock에서 1초 Tick과 1분 Tick을 만들고, 00:00부터 23:59까지 증가하는 HH:MM Counter를 FND 4자리에 표시합니다.

1s Tick 60s Counter 24-Hour HH:MM 1Hz DP Blink FND Multiplexing

시간 기준

100MHz의 100,000,000 Clock을 세어 1초 Tick을 생성합니다.

시계 Counter

60초 → 1분 Tick → HH:MM 증가 구조로 시간 단위를 계층화합니다.

표시

시·분 사이 Decimal Point를 1Hz Duty 50%로 점멸합니다.

HH:MM CLOCK FLOW

STEP 02

2. 100MHz에서 1초 Tick 생성

100MHz → 1초에 100,000,000 Clock
Counter 0부터 시작 → 비교값 99,999,999 
if (count_div == 27'd99_999_999) begin
    count_div <= 27'd0;
    tick_1s <= 1'b1;
end
else begin
    count_div <= count_div + 1'b1;
end

tick_1s는 새로운 Clock이 아니라 1 Clock 폭의 Enable 신호입니다.

STEP 03

3. 60초 Counter에서 1분 Tick 생성

if (tick_1s) begin
    if (sec_count == 6'd59) begin
        sec_count <= 6'd0;
        tick_1min <= 1'b1;
    end
    else begin
        sec_count <= sec_count + 1'b1;
    end
end
0초 → 1초 → ... → 58초 → 59초 → 0초
59 → 0 전환 순간 → tick_1min = 1
STEP 04

4. HH:MM Counter

assign carry_min_ones =
    (min_ones == 4'd9);

assign carry_min_tens =
    (min_ones == 4'd9) &&
    (min_tens == 4'd5);
신호범위역할
min_ones0~91분 자리
min_tens0~510분 자리
hour_ones시간에 따라 0~91시간 자리
hour_tens0~210시간 자리
12:58 → 12:59 → 13:00
STEP 05

5. 23:59 다음은 00:00

assign last_time =
    (hour_tens == 4'd2) &&
    (hour_ones == 4'd3) &&
    (min_tens == 4'd5) &&
    (min_ones == 4'd9);
if (last_time) begin
    min_ones  <= 4'd0;
    min_tens  <= 4'd0;
    hour_ones <= 4'd0;
    hour_tens <= 4'd0;
end
23:58 → 23:59 → 00:00 → 00:01
STEP 06

6. 시·분 사이 DP 1Hz Duty 50% Blink

100MHz → 0.5초 = 50,000,000 Clock
비교값 49,999,999 → blink 반전
0.5초 ON + 0.5초 OFF → 1Hz, Duty 50% 
if (count_blink == 26'd49_999_999) begin
    count_blink <= 26'd0;
    blink <= ~blink;
end

assign dp_state = ~blink;

Basys3의 DP는 Active-Low이므로 내부 blink를 반전해 출력합니다.

STEP 07

7. FND Scan과 Basys3 Top 통합

FND의 네 자리를 빠르게 순환 선택하고 현재 BCD 값 하나를 Decoder에 전달합니다.

fnd_mux_4digit u_mux(
    .digit0(min_ones),
    .digit1(min_tens),
    .digit2(hour_ones),
    .digit3(hour_tens),
    .digit_sel(digit_sel),
    .current_digit(current_digit),
    .an(an)
);

시와 분 사이 DP만 점멸하도록 Top에서 다음 조건을 사용합니다.

assign dp =
    (digit_sel == 2'd2) ? dp_state : 1'b1;

핵심 정리

  • 100MHz Clock 100,000,000개를 세어 1초 Tick을 생성합니다.
  • 60개의 1초 Tick을 세어 1분 Tick을 생성합니다.
  • HH:MM Counter는 분의 Carry를 시간 자리까지 전달하고 23:59 다음 00:00으로 복귀합니다.
  • 시·분 사이 DP는 0.5초마다 반전하여 1Hz Duty 50%로 점멸합니다.
  • FND Scan·MUX·Decoder는 앞선 Counter 실습과 동일한 구조를 재사용합니다.
  • 전체 시스템은 하나의 100MHz Clock Domain 안에서 Tick을 Enable로 사용합니다.
