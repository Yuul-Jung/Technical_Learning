Digital / FPGA · Chapter 02

SW0를 이용한 LED0 ON/OFF 실습

Basys3의 스위치 SW0를 입력으로 받아 LED0에 그대로 전달하는 가장 기본적인 FPGA 입출력 회로를 구현합니다. Verilog 소스 작성부터 XDC 핀 설정, Synthesis, Implementation, Bitstream 생성, 보드 다운로드까지 전체 흐름을 한 번에 확인합니다.

Basys3 Artix-7 XC7A35T Vivado 2024.2 Verilog HDL Ubuntu 24.04

입력

Basys3의 SW0 스위치를 FPGA 입력 포트 sw0로 받습니다.

핵심 논리

assign led0 = sw0; 한 줄로 입력 신호를 출력 LED에 직접 연결합니다.

완료 기준

SW0가 OFF이면 LED0 OFF, SW0가 ON이면 LED0 ON으로 동작하면 완료입니다.

전체 실습 흐름

SW0 입력→ sw0 포트→ assign→ led0 포트→ LED0 출력

1. 실습 개요

FPGA 보드의 입력 스위치 SW0를 이용하여 출력 LED0를 직접 제어합니다. 입력과 출력 사이에 별도의 상태 저장이나 복잡한 연산은 없으며, SW0의 논리값을 LED0에 그대로 전달합니다.

SW0 OFF → LED0 OFF    |    SW0 ON → LED0 ON
항목내용
FPGA BoardDigilent Basys3
FPGA DeviceArtix-7 XC7A35T
개발도구Vivado 2024.2
언어Verilog HDL
운영체제Ubuntu 24.04

실습에서 확인하는 핵심

  • FPGA 기본 입력·출력 구조
  • Verilog input, output, wire
  • 연속 할당문 assign
  • XDC를 이용한 보드 핀 연결
  • Vivado의 Synthesis → Implementation → Bitstream → Program Device 흐름

STEP 04

5. Verilog 코드 작성

module sw_led(
    input  wire sw0,
    output wire led0
);

assign led0 = sw0;

endmodule

코드 풀이 — 이 코드가 무엇을 하는가

코드역할
module sw_led이번 실습의 회로 모듈을 정의합니다.
input wire sw0Basys3의 SW0에서 FPGA 내부로 들어오는 1비트 입력입니다.
output wire led0FPGA 내부에서 Basys3 LED0 방향으로 나가는 1비트 출력입니다.
assign led0 = sw0;SW0의 현재 논리값을 LED0에 계속 전달합니다.
sw0가 LOW이면 led0도 LOW → LED0 OFF
sw0가 HIGH이면 led0도 HIGH → LED0 ON
검증 메모: 원본 자료의 전체 코드에는 assignled0=sw0;로 붙어 있는 표기가 있으나, 같은 자료의 코드 해설에는 assign led0 = sw0;로 제시되어 있습니다. 공개 실행본에서는 Verilog 문법상 정상인 assign led0 = sw0;를 사용합니다.
STEP 05

6. XDC 핀 설정

Add Sources → Add or Create Constraints
set_property PACKAGE_PIN V17 [get_ports sw0]
set_property IOSTANDARD LVCMOS33 [get_ports sw0]

set_property PACKAGE_PIN U16 [get_ports led0]
set_property IOSTANDARD LVCMOS33 [get_ports led0]
항목의미
PACKAGE_PIN보드 장치와 연결된 FPGA 물리 핀을 지정합니다.
get_portsVerilog Top 포트 이름을 지정합니다.
IOSTANDARD입출력 전기 규격을 설정합니다.

Basys3 핀 연결

보드 장치FPGA 핀Verilog 포트

Verilog 포트 이름과 XDC의 get_ports 이름은 대소문자까지 동일해야 합니다.

Verilog RTL → 합성 가능한 논리 구조

논리 구조 → FPGA 내부 배치 · 배선

11. 동작 확인

회로 관점

SW0 → FPGA 입력 포트 sw0 → 연속 할당 → 출력 포트 led0 → LED0

입력을 반전하거나 저장하지 않고 그대로 출력으로 전달하므로, 기능적으로는 단순한 버퍼 연결과 유사합니다.

12. 자주 발생하는 오류

포트 이름 불일치

sw0와 SW0는 서로 다른 이름입니다. Verilog와 XDC를 동일하게 맞춥니다.

XDC 핀 누락

Unconstrained Port

포트의 물리 핀 또는 I/O 제약이 누락되지 않았는지 확인합니다.

보드 연결 실패

  • USB 데이터 케이블 연결 확인
  • Basys3 전원 확인
  • Digilent Runtime 및 케이블 드라이버 설치 확인

핵심 정리

  • SW0 입력을 assign으로 LED0에 직접 연결하는 가장 기본적인 조합회로 실습입니다.
  • XDC는 Verilog 포트와 Basys3의 실제 핀을 연결합니다.
  • Vivado 기본 흐름은 RTL 작성 → XDC → Synthesis → Implementation → Bitstream → Program Device 순서입니다.
  • 다음 실습부터는 이 기본 입출력 구조에 논리게이트, 조합회로, 순차회로를 단계적으로 추가할 수 있습니다.
