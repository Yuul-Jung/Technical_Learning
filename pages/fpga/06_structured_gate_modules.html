STEP 01

1. 왜 구조화해서 설계하는가?

이전 실습에서는 Top Module 안에서 각 논리식을 직접 작성했습니다. 이번 실습에서는 각 Gate를 독립된 Module로 만들고, Top에서는 Module을 연결하는 방식으로 확장합니다.

하나의 큰 코드 → 기능별 Module 분리 → Top에서 Instance → 계층적 RTL
구분역할
Gate ModuleNOT, BUFFER, AND, OR, NAND, NOR, XOR의 실제 논리 기능 담당
gate_topSW·LED 포트를 선언하고 Gate Module을 Instance하여 연결
XDCTop 포트와 Basys3 실제 핀 연결

STEP 03

3. Gate Module 작성

Module기능핵심 식
g_not_7404NOTY = ~A
g_buffer_7407BUFFERY = A
g_and_7408ANDY = A & B
g_or_7432ORY = A | B
g_nand_7400NANDY = ~(A & B)
g_nor_7402NORY = ~(A | B)

예: AND Gate

module g_and_7408(
    input a,
    input b,
    output y
);

assign y = a & b;

endmodule

나머지 Gate도 같은 형태로 입력 → 논리식 → 출력 구조를 유지합니다.

STEP 04

4. Top Module 구성

Top Module은 Gate 기능을 직접 구현하지 않고, SW 입력과 LED 출력 사이에 각 Gate Module을 Instance합니다.

module gate_top(
    input [1:0] sw,
    output [6:0] led
);

    .y(led[0])

STEP 05

5. Module과 Instance

Module은 회로를 정의하는 블록이고, Instance는 정의된 Module을 상위 회로 안에서 실제로 사용하는 회로 생성 단위입니다.

Module 정의 → Instance 생성 → 포트 연결 → FPGA 내부 회로 구성
// Module 정의
module g_and_7408(
    input a,
    input b,
    output y
);
assign y = a & b;
endmodule

// gate_top 내부 Instance
g_and_7408 u_and_7408(
    .a(sw[0]),
    .b(sw[1]),
    .y(led[2])
);
같은 Module을 여러 번 Instance하면 동일 기능의 회로 블록을 상위 회로 안에서 여러 개 사용할 수 있습니다.

STEP 07

7. RTL Schematic 확인

  • Elaborated Design에서 gate_top 아래 각 Gate Module Instance가 연결되는지 확인합니다.
  • RTL Schematic에서 SW0·SW1이 여러 Gate로 분기되고 각 결과가 LED0~LED6으로 연결되는지 확인합니다.
gate_top → u_not_7404 / u_buffer_7407 / u_and_7408 / … → LED0 ~ LED6
검증 메모: Synthesis 이후에는 단순 Gate가 FPGA의 LUT 등으로 최적화될 수 있으므로 최종 합성 구조가 74 시리즈 IC 기호 그대로 보이는 것은 아닙니다.
STEP 08

핵심 정리

  • Gate 기능을 개별 Module로 분리하면 재사용과 계층적 설계가 쉬워집니다.
  • Top Module은 Gate 기능을 다시 작성하지 않고 Instance와 연결을 담당합니다.
  • Module은 회로 정의이고 Instance는 그 정의를 실제 상위 회로에서 사용하는 회로 블록입니다.
  • Vivado의 Elaborated Design과 RTL Schematic을 통해 계층 구조와 연결 관계를 확인합니다.
