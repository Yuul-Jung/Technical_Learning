SECTION 01

AXI는 무엇인가

AXI(Advanced eXtensible Interface, 고급 확장 인터페이스)는 CPU 자체가 아니라 IP 간 데이터 전송 규칙을 정의하는 Bus/Interface Protocol입니다. MicroBlaze와 GPIO, UART, Timer, Custom IP를 연결할 때도 AXI 규칙에 따라 Address, Data, Response가 전달됩니다.

SECTION 02

세 가지 AXI 계열 구분

구분주소대표 용도
AXI4있음고성능 Memory-Mapped Burst
AXI4-Lite있음Control / Status Register
AXI4-Stream없음Video, DSP, NPU Data Stream

AXI4-Stream에서 Source는 TVALID를, Receiver는 TREADY를 구동합니다. 두 신호가 모두 1인 Clock Edge에서 Transfer가 성립합니다. Receiver가 준비되지 않았으면 Source는 유효 데이터를 유지해야 합니다.

SECTION 04

NPU와 AXI

MicroBlaze Control → AXI4-Lite → NPU Register / Feature Data → AXI4-Stream 또는 BRAM → MAC Datapath

따라서 AXI4-Lite는 제어에, AXI4-Stream은 대량의 연속 데이터 흐름에 적합하다는 구분이 NPU 통합에서도 그대로 사용됩니다.

SUMMARY

핵심 정리

  • 메모리·고성능 데이터 전송에 사용합니다.
  • Control/Status Register 접근에 적합합니다.
  • 주소 없이 연속 데이터를 VALID/READY로 전달합니다.
