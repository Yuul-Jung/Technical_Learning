SECTION 02

Quantization의 의미

FP32 Weight와 Activation을 그대로 작은 Artix-7 FPGA에서 대규모로 처리하면 자원과 메모리 부담이 큽니다. INT8 Quantization은 값의 표현 범위를 줄여 Memory Size와 Arithmetic Resource 요구량을 낮추는 대표적 방법입니다.

Quantization은 단순히 자료형 이름을 바꾸는 작업이 아닙니다. Scale, Zero Point, Saturation, Accumulator Bit Width와 Accuracy 변화를 검증해야 합니다.

SECTION 03

Weight · Activation · MAC

Input Activation → BRAM/Buffer → Weight Read → DSP48E1 Multiply → Accumulator → Activation/Output

여러 MAC Unit을 병렬 배치하면 Throughput을 높일 수 있지만 DSP와 BRAM Port, Routing, Power, Timing 사용량이 증가합니다.
