SECTION 02

Distributed RAM과 BRAM

UG474의 SLICEM LUT는 작은 Distributed RAM이나 Shift Register로 구성할 수 있습니다. 반면 7 Series의 Block RAM은 더 큰 저장 공간을 제공하고 Dual-Port 구조와 다양한 Width/Depth 구성을 지원합니다.

자원적합한 용도
Distributed RAM작은 Table, Delay, 작은 Buffer
BRAMWeight, Feature Buffer, FIFO, Program/Data Memory

SECTION 03

DSP48E1

UG479의 DSP48E1 Slice는 Multiply, Multiply-Accumulate, Add/Subtract, Pattern Detect 등의 연산을 지원하는 전용 Arithmetic Resource입니다. NPU의 MAC(Multiply-Accumulate, 곱셈-누산) 구조와 직접 연결됩니다.

Input × Weight → Multiply → Accumulate → Pipeline Register
SECTION 04

Resource 균형

FPGA Accelerator는 LUT만 많이 쓰는 것이 좋은 설계가 아닙니다. BRAM Bandwidth, DSP 수, Pipeline Stage, Routing, Clock Frequency를 함께 고려해야 합니다. Basys3 XC7A35T의 자원 한도 안에서 병렬도와 메모리 구조를 조절하는 것이 핵심입니다.
