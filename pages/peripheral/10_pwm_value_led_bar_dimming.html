PWM_VALUE 기반 LED Bar Dimming RTL 실습

Chapter 09의 UART Register Map · CdS · FND 구조는 그대로 유지하고, led_pwm_controller.v 하나만 수정합니다. 이제 PWM_VALUE 하나가 LED의 PWM 밝기와 LED Bar의 개수를 동시에 결정합니다.

PWM_VALUE LED Bar 8-bit PWM 16-Level Minimal Change

기존

LED 16개가 모두 같은 PWM 밝기로 동시에 켜졌습니다.

변경

PWM_VALUE가 커질수록 LED 밝기와 켜지는 개수가 함께 증가합니다.

수정 범위

STEP 04

4. led_count 계산

assign led_count =
    (pwm_value == 8'd0) ? 5'd0 :
    (({1'b0, pwm_value} + 9'd15) >> 4);

핵심은 (pwm_value + 15) / 16의 올림 계산입니다. 16으로 나누는 동작은 오른쪽 4-bit Shift로 구현합니다.

pwm_value = 64 → (64 + 15) >> 4 → 79 >> 4 → 4 pwm_value = 128 → (128 + 15) >> 4 → 143 >> 4 → 8
중요: {1'b0, pwm_value}로 9-bit로 확장한 뒤 15를 더합니다. 그렇지 않으면 8-bit에서 255 + 15 계산이 Overflow할 수 있습니다.
STEP 05

5. led_level_mask 생성

assign led_level_mask =
    (led_count == 5'd0)  ? 16'h0000 :
    (led_count >= 5'd16) ? 16'hFFFF :
    ((16'h0001 << led_count) - 16'h0001);

6. PWM 밝기와 LED 개수를 동시에 적용

if (pwm_enable && pwm_active) begin
    led = led_level_mask;
end

pwm_value ├→ pwm_active → 얼마나 오래 켤 것인가 └→ led_level_mask → 몇 개를 켤 것인가

하나의 PWM_VALUE가 시간축의 Duty와 공간축의 LED Bar 길이를 동시에 제어합니다.

검증 메모: pwm_active = (pwm_counter < pwm_value)이므로 0xFF의 Duty는 정확히 100%가 아니라 255/256 ≈ 99.6%입니다. LED 개수는 16개가 맞지만 밝기는 “거의 최대”로 표현하는 것이 정확합니다.
업로드된 참고자료에는 이번 단계에서 별도 Testbench 변경을 요구하지 않고, led_pwm_controller.v 한 파일만 수정하도록 되어 있습니다. 따라서 불필요한 신규 Testbench는 추가하지 않았습니다.

핵심 정리

  • PWM_VALUE 하나로 LED 밝기와 LED Bar 개수를 동시에 제어합니다.
  • 0~255의 값을 0~16개 LED로 변환하기 위해 올림 나눗셈 (value+15)>>4를 사용합니다.
  • led_level_mask가 실제로 켤 LED의 위치와 개수를 결정합니다.
  • PWM Duty는 시간축, LED Mask는 공간축의 표시량을 담당합니다.
  • CdS/FND/Register Map 구조는 수정하지 않고 LED PWM Controller만 최소 변경합니다.
