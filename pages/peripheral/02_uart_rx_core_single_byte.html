RTL 주변기기 회로설계 · 02

UART RX Core · 1문자 수신 RTL 실습

PC에서 들어오는 UART 8N1 신호를 2-FF로 동기화하고, 16x Oversampling으로 비트 중앙을 찾아 D0~D7을 수신한 뒤 정상 Byte를 16Byte FIFO에 저장합니다.

UART RX 8N1 2-FF Synchronizer 16x Oversampling 16Byte FIFO

동기화

RsRx는 외부 비동기 입력이므로 2단 Flip-Flop을 거쳐 FSM에 전달합니다.

샘플링

9600bps를 16배 Oversampling하여 Start·Data·Stop Bit의 중앙에서 값을 확인합니다.

버퍼링

정상 수신된 1Byte는 FIFO에 저장되고 rx_valid / rx_ready로 읽습니다.

정상 수신된 Byte만 FIFO에 저장합니다. Stop Bit 오류는 frame_error, FIFO Full 상태의 추가 수신은 overrun_error로 구분합니다.

STEP 02

2. 비동기 RsRx 입력을 2-FF로 동기화

always @(posedge clk) begin
    if (reset) begin
        rx_meta_reg <= 1'b1;
        rx_sync_reg <= 1'b1;
    end
    else begin
        rx_meta_reg <= rx_async;
        rx_sync_reg <= rx_meta_reg;
    end
end
RsRx → rx_meta_reg → rx_sync_reg → UART RX FSM
UART 입력은 FPGA의 100MHz Clock과 비동기입니다. 2-FF Synchronizer(동기화기)는 외부 RX 신호를 내부 Clock 기준으로 정리하고 메타안정성 전파 위험을 줄이는 역할을 합니다.

STEP 04

4. UART RX FSM — 중앙 샘플링

S_IDLE→ S_START→ S_DATA→ S_STOP→ S_IDLE

Start Bit

if (rx_sync == 1'b0)
    state <= S_START;

처음 0이 보였다는 이유만으로 Start Bit를 확정하지 않습니다. 16x Oversampling의 반 비트 위치인 8번째 Sample 부근까지 기다린 뒤 중앙에서도 0인지 다시 확인합니다.

Data Bit

shift_reg[bit_count] <= rx_sync;

이후 16 Sample Tick마다 다음 Data Bit 중앙을 읽으며, UART는 LSB First이므로 첫 번째 Data Bit를 shift_reg[0]에 저장합니다.

STEP 07

7. UART RX Core의 rx_valid / rx_ready

output [7:0] rx_data;
output       rx_valid;
input        rx_ready;
FIFO에 데이터 존재 → rx_valid=1 → Consumer가 rx_ready=1 → FIFO에서 1Byte Read

현재 원본 Top Module에서는 데이터를 오래 쌓아두지 않고 다음처럼 즉시 읽습니다.

assign rx_ready = rx_valid;
검증 메모: 이 자료는 원본의 rx_valid / rx_ready 기반 FIFO 인터페이스를 그대로 유지합니다. 이후 재사용 가능한 주변기기 라이브러리로 확장할 때는 현재 프로젝트의 표준 Byte Stream 인터페이스와 연결 관계를 별도 챕터에서 정리합니다.

핵심 정리

  • 외부 UART RX는 2-FF Synchronizer를 거쳐 FPGA Clock에 동기화합니다.
  • 9600bps 수신은 16x Oversampling을 사용하며 100MHz 기준 CLKS_PER_SAMPLE=651입니다.
  • Start Bit는 처음 0을 검출한 뒤 반 비트 위치에서 다시 확인하여 Noise를 걸러냅니다.
  • D0~D7을 LSB First로 수신하고 Stop Bit가 1일 때만 정상 Byte를 확정합니다.
  • 정상 Byte는 8bit × 16 FIFO에 저장하며 rx_valid / rx_ready로 읽습니다.
  • Frame Error와 FIFO Overrun을 별도 오류 신호로 구분합니다.
