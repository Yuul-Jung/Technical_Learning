RTL 주변기기 회로설계 · 14

LED Breathing Mode · PWM_VALUE 0xFE RTL 실습

기존 LED PWM(피더블유엠, 펄스폭 변조) + LED Bar 구조는 유지하고, PWM_VALUE = 0xFE를 특수 모드 값으로 예약합니다. 숨쉬기 모드에서는 FPGA 내부의 breath_value가 자동으로 증가·감소하며 LED 밝기와 LED Bar 길이가 함께 천천히 변합니다.

Breathing Effect PWM_VALUE = 0xFE breath_value active_pwm_value Top 수정 없음

일반 모드

0x00~0xFD, 0xFF는 기존 LED Bar Dimming입니다.

숨쉬기 모드

0xFE이면 내부 breath_value를 사용합니다.

수정 범위

led_pwm_controller.v 한 파일만 수정합니다.

STEP 01

1. 수정 범위 — LED PWM Controller 하나만 변경

구분파일
수정led_pwm_controller.v
하위 검증tb_led_pwm_controller_breathing.v
수정하지 않음Top, CdS, FND, Register Map, UART, 초음파 거리계, XDC

Top Module에는 기능 로직을 추가하지 않습니다. 기존 pwm_value 인터페이스 안에서 특수값 하나만 예약하여 모드를 선택합니다.

STEP 02

2. PWM_VALUE = 0xFE를 숨쉬기 모드로 예약

PWM_VALUE동작
0x00 ~ 0xFD일반 LED Bar Dimming
0xFELED Breathing Mode
0xFF일반 LED Bar Dimming · 거의 최대 밝기
 
assign breath_mode =
    (pwm_value == 8'hFE);
주의: 0xFE는 숨쉬기 모드 진입값으로 예약되므로 일반 밝기값으로 사용하지 않습니다.
STEP 03

3. active_pwm_value로 기존 회로를 그대로 재사용

assign active_pwm_value =
    breath_mode ? breath_value : pwm_value;

assign pwm_active =
    (pwm_counter < active_pwm_value);
일반 모드 → active_pwm_value = pwm_value 숨쉬기 모드 → active_pwm_value = breath_value

이후의 PWM 비교, LED 개수 계산, LED Mask 생성 회로는 active_pwm_value만 사용하므로 기존 LED Bar 구조를 그대로 유지할 수 있습니다.

STEP 04

4. 숨쉬기 속도를 만드는 BREATH_PRESCALE

parameter PWM_PRESCALE    = 390;
parameter BREATH_PRESCALE = 200_000;

assign breath_tick =
    (breath_prescale_counter ==
     (BREATH_PRESCALE - 1));
100 MHz Clock → 10 ns / Clock 200,000 Clock → 약 2 ms 따라서 breath_value → 약 2 ms마다 1단계 변화

계산상 0에서 255까지 약 510ms, 다시 255에서 0까지 약 510ms이므로 한 번의 밝아짐→어두워짐 주기는 약 1.02초입니다.

STEP 05

5. breath_value 증가·감소

0

→ 254

→ 254

→ 반복
if (breath_up) begin
    if (breath_value == 8'hFF) begin
        breath_up    <= 1'b0;
        breath_value <= breath_value - 8'd1;
    end
    else begin
        breath_value <= breath_value + 8'd1;
    end
end
else begin
    if (breath_value == 8'h00) begin
        breath_up    <= 1'b1;
        breath_value <= breath_value + 8'd1;
    end
    else begin
        breath_value <= breath_value - 8'd1;
    end
end
breath_up=1이면 증가, breath_up=0이면 감소합니다. 최대·최소값에서 방향만 바꾸는 삼각파 형태의 밝기값입니다.
STEP 06

6. 숨쉬기 밝기와 LED Bar 길이가 함께 변한다

assign led_count =
    (active_pwm_value == 8'd0) ? 5'd0 :
    (({1'b0, active_pwm_value} + 9'd15) >> 4);

assign led_level_mask =
    (led_count == 5'd0)  ? 16'h0000 :
    (led_count >= 5'd16) ? 16'hFFFF :
    ((16'h0001 << led_count) - 16'h0001);
breath_value 증가 → PWM Duty 증가 → LED Bar 개수 증가 → 더 밝고 길게 보임 breath_value 감소 → PWM Duty 감소 → LED Bar 개수 감소 → 더 어둡고 짧게 보임
검증 메모: 원본 RTL의 breath_value 생성기는 breath_mode가 아닐 때도 계속 동작합니다. 따라서 0xFE로 진입할 때 항상 0부터 다시 시작하는 것이 아니라, 그 시점의 내부 breath_value 단계부터 숨쉬기 효과가 표시됩니다. 원본 코드는 그대로 유지했습니다.
STEP 07

7. moserial 보드 확인

moserial HEX의미기대 동작
010001CTRL[0]=1LED PWM Enable
010100PWM_VALUE=0x00LED OFF
010140PWM_VALUE=0x40약 4개 · 낮은 밝기
010180PWM_VALUE=0x80약 8개 · 중간 밝기
0101C0PWM_VALUE=0xC0약 12개 · 높은 밝기
0101FEPWM_VALUE=0xFE숨쉬기 모드

010001 → LED 기능 ON 0101FE → 서서히 밝아짐 → 최대 근처 → 서서히 어두워짐 → 반복 010180 → 일반 LED Bar 모드 복귀
위 동작은 참고자료의 보드 확인 기준이며, 이번 생성 과정에서 실제 Basys3 측정 결과를 새로 만든 것은 아닙니다.
STEP 08

8. 하위 모듈 Testbench

시뮬레이션 시간을 줄이기 위해 Testbench에서는 두 Prescaler를 모두 4로 낮춥니다. 

led_pwm_controller #(
    .PWM_PRESCALE(4),
    .BREATH_PRESCALE(4)
) dut (...);
단계설정검증
1ctrl_reg=0x01, pwm_value=0x80일반 LED Bar 동작
2pwm_value=0xFELED 패턴 변화 횟수 확인
3change_count ≥ 5변화가 충분히 발생
4nonzero_count ≥ 5LED가 실제로 켜짐
 
PASS: LED breathing mode produced changing LED patterns.

nonzero_count=...
실행 결과 구분: 위 PASS 문구는 참고자료가 제시한 기대 Simulation 출력입니다. 현재 생성 환경에서 Verilog Simulator를 실행한 실제 Output으로 표시하지 않았습니다.

핵심 정리

  • PWM_VALUE=0xFE를 숨쉬기 모드 진입용 특수값으로 예약합니다.
  • 일반 모드에서는 pwm_value, 숨쉬기 모드에서는 breath_value를 사용합니다.
  • breath_value는 0→255→0으로 반복하며 LED 밝기와 Bar 길이를 함께 변화시킵니다.
  • 100MHz, BREATH_PRESCALE=200000이면 밝기값은 약 2ms마다 한 단계 바뀝니다.
  • Top Module은 수정하지 않고 led_pwm_controller.v 내부만 변경합니다.
  • 0xFE는 일반 밝기값으로 사용하지 않습니다.
