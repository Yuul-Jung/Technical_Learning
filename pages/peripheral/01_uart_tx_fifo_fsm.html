RTL 주변기기 회로설계 · 01

UART TX · FIFO · Sender · 8N1 FSM RTL 실습

Basys3의 버튼을 한 번 누를 때마다 ASCII 문자를 TX FIFO에 저장하고, Sender가 1Byte씩 꺼내 UART TX FSM으로 전달하여 PC에 9600bps 8N1 형식으로 송신합니다.

UART TX9600 bps8N116-Byte FIFOFSM

입력

btnC → Debounce → 1-Clock btn_pulse

Buffer

16Byte FIFO가 FPGA 내부 속도와 느린 UART 송신 속도의 차이를 흡수합니다.

출력

Idle → Start → D0~D7 → Stop 순서로 RsTx를 출력합니다.

STEP 01

1. UART TX 전체 구조

btnC

   └─ uart_tx_fsm

UART(Universal Asynchronous Receiver/Transmitter, 범용 비동기 송수신)는 별도 Clock 선 없이 송수신 측이 같은 Baud Rate를 기준으로 데이터를 주고받습니다. 이번 단계는 TX(Transmit, 송신) 경로만 구현합니다.

STEP 02

2. Button Pulse와 ASCII 문자 생성

기계식 버튼은 Chapter 22에서 만든 것과 같은 흐름으로 동기화·디바운스한 뒤 1-Clock Pulse로 사용합니다.

btnC → 2-FF 동기화 → 약 20ms Debounce → btn_pulse 1 Clock
if (btn_pulse && !tx_full) begin
    tx_wr_data <= ascii_reg;
    tx_wr_en   <= 1'b1;

    if (ascii_reg == 8'h7A)
        ascii_reg <= 8'h61;
    else
        ascii_reg <= ascii_reg + 1'b1;
end
8'h61 = 'a' → b → c → ... → z(8'h7A) → a
STEP 03

3. UART TX FIFO — 16Byte 송신 대기열

FPGA 내부는 100MHz로 매우 빠르게 동작하지만 UART 송신은 훨씬 느립니다. FIFO(First In First Out, 먼저 들어온 데이터가 먼저 나가는 버퍼)가 두 속도 사이의 차이를 흡수합니다.

구성역할
mem[0:15]8bit × 16개 데이터 저장
wr_ptr다음 Write 위치
rd_ptr다음 Read 위치
count_reg현재 저장 Byte 수 0~16
full / emptyWrite/Read 가능 여부
case ({wr_en && !full, rd_en && !empty})
    2'b10: Write만 수행
    2'b01: Read만 수행
    2'b11: Write + Read 동시 수행
    default: 상태 유지
endcase
STEP 04

4. uart_tx_sender — FIFO와 TX FSM 사이의 관리자

S_IDLE → S_WAIT_BUSY → S_WAIT_DONE → S_IDLE
if (!fifo_empty && !tx_busy) begin
    tx_data    <= fifo_rd_data;
    tx_start   <= 1'b1;
    fifo_rd_en <= 1'b1;
    state_reg  <= S_WAIT_BUSY;
end

tx_start와 fifo_rd_en은 모두 1-Clock Pulse입니다. Sender는 TX FSM이 실제로 tx_busy=1이 되었는지 확인한 뒤 송신 완료까지 기다립니다.

STEP 05

5. uart_tx_fsm — UART 8N1 직렬 송신

Idle 1 → Start 0 → D0 → D1 → D2 → D3 → D4 → D5 → D6 → D7 → Stop 1
상태역할
S_IDLETX Line을 1로 유지하며 tx_start 대기
S_STARTStart Bit 0을 1 Bit 시간 유지
S_DATAD0~D7을 LSB First로 송신
S_STOPStop Bit 1을 1 Bit 시간 유지 후 tx_done 발생
if (bit_timer == CLKS_PER_BIT - 1) begin
    bit_timer <= 32'd0;
    ...
end

8N1은 Data 8bit, Parity 없음(N), Stop Bit 1개를 의미합니다.

STEP 06

6. 100MHz · 9600bps의 CLKS_PER_BIT

100,000,000 / 9,600 ≈ 10,416.67 → 정수 근사값 10,417
parameter CLKS_PER_BIT = 10417;

따라서 UART의 한 Bit는 Basys3 100MHz Clock 약 10,417개 동안 유지됩니다. 8N1 한 프레임은 Start 1 + Data 8 + Stop 1로 총 10 Bit입니다.

9600bps에서 1Byte 프레임 시간의 근사값은 10 / 9600 ≈ 1.0417ms입니다. 실제 회로는 정수 Clock 수를 사용하므로 작은 근사 오차가 포함됩니다.
STEP 07

uart_tx_core는 FIFO, Sender, TX FSM을 하나의 TX Core로 묶습니다.

핵심 정리

  • 버튼 입력은 Debounce 후 1-Clock Pulse로 변환해 송신 요청에 사용합니다.
  • FIFO는 최대 16Byte의 송신 대기 데이터를 순서대로 저장합니다.
  • Sender는 fifo_empty와 tx_busy를 확인해 한 Byte씩 TX FSM에 전달합니다.
  • TX FSM은 8N1 형식으로 Start 0 → D0~D7 → Stop 1을 직렬 출력합니다.
  • 100MHz / 9600bps 기준 CLKS_PER_BIT=10417을 사용합니다.
  • Top은 btnC → ASCII → FIFO → Sender → FSM → RsTx 흐름을 연결합니다.
