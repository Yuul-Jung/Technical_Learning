RTL 주변기기 회로설계 · 09

UART Register Map · CdS + LED PWM + FND RTL 실습

08의 UART Register Map을 그대로 확장합니다. CTRL[0]은 LED PWM, CTRL[1]은 CdS 상태 표시 Enable로 사용하고, 외부 CdS 디지털 입력 JA[0]을 2-FF 동기화하여 FND에 L--- 또는 d---를 표시합니다.

Register Bit Field CdS 2-FF Synchronizer LED PWM FND Status

CTRL[0]

LED PWM(피더블유엠, 펄스폭 변조) 출력 Enable입니다.

CTRL[1]

CdS(씨디에스, 황화카드뮴) 상태를 FND에 표시할지 결정합니다.

JA[0]

외부 CdS 회로의 디지털 출력으로, 밝음 1 · 어두움 0 기준입니다.

STEP 02

2. CTRL Register를 Bit Field로 사용

CTRL Bit이름기능현재 사용
CTRL[0]led_pwm_enLED PWM Enable사용
CTRL[1]cds_enCdS FND 상태 표시 Enable사용
CTRL[2]dist_en초음파 거리 기능향후
CTRL[3]motor_en모터 제어 기능향후
CTRL[7:4]Reserved확장용향후
중요: Chapter 08에서는 ctrl_reg == 8'h01일 때 PWM을 켰지만, 이번에는 CTRL[1]도 동시에 사용할 수 있어야 하므로 PWM Enable 조건을 ctrl_reg[0]으로 변경합니다. 
// 기존
assign pwm_enable = (ctrl_reg == 8'h01);

// 변경
assign pwm_enable = ctrl_reg[0];
STEP 03

3. CTRL Packet 조합

PacketCTRL[1:0]LED PWMCdS FND
01 00 0000OFF----
01 00 0101ON----
01 00 0210OFFL--- / d---
01 00 0311ONL--- / d---
01 00 03 → CMD=Write → ADDR=CTRL → DATA=0x03 → CTRL[0]=1 + CTRL[1]=1 → LED PWM + CdS 표시 동시 ON

PWM_VALUE는 계속 ADDR=0x01을 사용합니다.

STEP 04

4. CdS 입력의 의미

CdS는 빛의 세기에 따라 저항이 변하는 광도전 소자입니다. 이번 RTL에서는 아날로그 저항값을 FPGA가 직접 읽지 않고, 외부 회로가 이미 밝음/어두움을 1-bit 디지털 신호로 만들어 JA[0]에 전달합니다.

주변 상태외부 출력JA[0]내부 판단
밝음 / 낮11cds_is_light=1
어두움 / 밤00cds_is_light=0
입력 반전은 FPGA 내부에서 수행하지 않습니다. 필요한 극성 변환은 외부 CdS 회로에서 처리한다는 것이 원본 설계 기준입니다.
STEP 05

5. cds_input_filter — 외부 입력 2-FF 동기화

always @(posedge clk) begin
    if (reset) begin
        cds_meta     <= 1'b0;
        cds_sync_reg <= 1'b0;
    end
    else begin
        cds_meta     <= cds_sw_raw;
        cds_sync_reg <= cds_meta;
    end
end

assign cds_sw_sync  = cds_sync_reg;
assign cds_is_light = cds_sync_reg;
JA[0] → cds_meta → cds_sync_reg → cds_is_light

외부 CdS 입력은 FPGA의 시스템 Clock과 비동기이므로 2-FF Synchronizer(투 플립플롭 동기화기)를 사용해 Clock 영역 안으로 가져옵니다.

STEP 06

6. FND(에프엔디, 7-세그먼트 표시기) 상태 표시

조건상태 코드FND
CTRL[1]=0무관----
CTRL[1]=1, 밝음4'hAL---
CTRL[1]=1, 어두움4'hBd---
 
4'hA → L → seg = 7'b1000111
4'hB → d → seg = 7'b0100001
4'hC → - → seg = 7'b0111111

하위 3자리 숫자 표시 인터페이스도 남겨 두지만, 이번 CdS 단계에서는 value_valid=0으로 두어 모두 -로 표시합니다.

원본 Top에 있던 cds_is_light ? 4'hA : 4'hB 선택식은 현재 홈페이지의 Top Shell 원칙에 맞춰 cds_status_encoder.v로 분리했습니다. 표시 결과와 코드값은 원본과 동일합니다.

참고자료에 포함된 CdS/FND 이미지는 임시 서명 URL이므로 GitHub Pages에 직접 삽입하지 않았습니다. 실제 회로 사진이나 Vivado Waveform은 Repository의 images/에 저장한 뒤 상대경로로 추가하는 방식이 적합합니다.

핵심 정리

  • Chapter 08의 Register Map을 유지하면서 CTRL을 Bit Field 방식으로 확장합니다.
  • CTRL[0]은 LED PWM, CTRL[1]은 CdS FND 표시 Enable입니다.
  • 외부 CdS 디지털 입력 JA[0]은 2-FF 동기화를 거쳐 사용합니다.
  • 밝음은 L---, 어두움은 d---, CdS 기능 OFF는 ----로 표시합니다.
  • Register Map을 확장하면 이후 거리 센서·모터 등도 CTRL bit와 별도 Register를 통해 누적할 수 있습니다.
