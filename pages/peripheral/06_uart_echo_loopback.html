RTL 주변기기 회로설계 · 06

UART Echo · RX → TX Loopback RTL 실습

PC에서 전송한 1Byte를 Basys3 UART RX가 수신하고, Echo Controller가 그 Byte를 UART TX 경로로 그대로 전달하여 다시 PC로 돌려보냅니다.

UART Echo RX → TX Byte Stream Backpressure Basys3

RX

rx_valid과 rx_data가 수신 Byte를 Echo Controller에 전달합니다.

Echo

수신 Byte를 변경하지 않고 TX FIFO 입력으로 그대로 전달합니다.

TX

TX FIFO에 공간이 없으면 RX FIFO를 읽지 않고 대기합니다.

Echo 전체 흐름

PC TX→ Basys3 RsRx→ UART RX FIFO→ Echo Controller→ UART TX FIFO→ RsTx → PC RX
STEP 01

1. 목표 — 받은 Byte를 그대로 되돌려 보내기

PC에서 'A' 전송 → Basys3 RX에서 0x41 수신 → Echo Controller → Basys3 TX에서 0x41 송신 → PC에서 다시 'A' 수신

Echo는 UART RX와 UART TX가 실제로 연결되어 동작하는지를 확인하는 가장 단순한 응용입니다. 데이터 해석이나 Command Parser는 아직 수행하지 않습니다.

STEP 02

2. 기존 Core는 수정하지 않음

uart_rx_core.v   → 유지
uart_tx_core.v   → 유지
uart_core.v      → 유지

신규:
uart_echo_controller.v
basys3_uart_echo_top.v
tb_uart_echo_controller.v

Echo 기능을 RX Core나 TX Core 내부에 넣지 않고, 두 Core 사이에 별도의 Controller를 둡니다.

STEP 03

3. 참고자료의 Echo 제어 방식

참고자료의 Echo Controller는 RX에서 rx_valid이 발생하고 TX가 tx_busy=0일 때 tx_start를 1 Clock 발생시키는 구조입니다. 

if (rx_valid && !tx_busy) begin
    tx_data  <= rx_data;
    tx_start <= 1'b1;
end
이 코드는 참고자료 당시의 TX Core가 tx_start / tx_data 인터페이스를 직접 공개하던 구조를 기준으로 합니다.
STEP 04

4. 현재 UART Library 인터페이스에 맞춘 연결

현재 누적 사이트의 uart_core는 TX FIFO를 포함하고 있으므로 외부 인터페이스가 tx_wr_en / tx_wr_data / tx_full입니다. 따라서 Echo 동작 의미는 유지하면서 현재 Core 인터페이스에 맞게 연결합니다.

참고자료 구조현재 Library 대응
rx_validrx_valid
rx_datarx_data
tx_busytx_full을 이용한 수신 Backpressure
tx_starttx_wr_en
tx_datatx_wr_data
검증 메모: 아래 Controller는 참고자료의 기능을 현재 프로젝트의 FIFO 기반 UART Core에 맞춘 현재 Library용 구현입니다. 참고자료의 tx_start / tx_busy 코드를 그대로 복사한 것이 아닙니다.
STEP 05

5. uart_echo_controller

assign transfer = rx_valid && !tx_full;

assign rx_ready   = transfer;
assign tx_wr_en   = transfer;
assign tx_wr_data = rx_data;
RX FIFO에 Byte 있음 + TX FIFO 공간 있음 → 같은 Clock Edge에서 RX FIFO Read + TX FIFO Write

TX FIFO가 Full이면 rx_ready=0이므로 RX FIFO의 현재 Byte를 소비하지 않습니다. TX FIFO에 공간이 생긴 뒤 같은 Byte를 전달합니다.

STEP 06

6. Basys3 Echo Top

uart_core u_uart_core (...);

uart_echo_controller u_uart_echo_controller (
    .rx_valid   (rx_valid),
    .rx_data    (rx_data),
    .rx_ready   (rx_ready),
    .tx_full    (tx_full),
    .tx_wr_en   (tx_wr_en),
    .tx_wr_data (tx_wr_data)
);
RsRx → uart_core RX → Echo Controller → uart_core TX → RsTx

Top Module에는 Echo 기능을 직접 작성하지 않고 UART Core와 Echo Controller를 연결하는 Shell/Wrapper 역할만 둡니다.

STEP 08

8. 보드 성공 기준

PC TX : Aa10
          ↓
Basys3 UART Echo
          ↓
PC RX : Aa10

Hex:
41 61 31 30

참고자료의 성공 기준은 Python Echo Test에서 Aa10을 송신했을 때 RX Hex가 41613130으로 돌아오는 것입니다.

위 값은 참고자료에 제시된 성공 기준입니다. 이번 생성 과정에서 실제 Basys3 보드나 Python 프로그램을 실행한 결과는 아닙니다.

핵심 정리

  • UART Echo는 RX로 받은 Byte를 변경하지 않고 TX로 그대로 다시 송신하는 구조입니다.
  • 기존 UART RX/TX Core는 수정하지 않고 별도 Echo Controller만 추가합니다.
  • 현재 UART Library에서는 RX의 valid/ready와 TX FIFO의 wr_en/full을 연결합니다.
  • TX FIFO가 Full이면 RX FIFO를 읽지 않아 Backpressure가 적용됩니다.
  • Top Module은 보드 핀과 UART Core, Echo Controller 연결만 담당합니다.
  • 다음 단계에서는 Echo 이후 Command/Response 또는 Register Map 제어로 확장할 수 있습니다.
