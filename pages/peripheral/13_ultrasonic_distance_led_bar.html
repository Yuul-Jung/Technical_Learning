초음파 거리 기반 LED Bar 재사용 RTL 실습

HC-SR04에서 측정한 distance_cm을 직접 LED Mask로 바꾸지 않습니다. 새로 추가한 distance_to_pwm_value_controller.v가 거리값을 기존 pwm_value 형식으로 변환하고, Chapter 10의 led_pwm_controller.v를 그대로 재사용합니다.

Module Reuse CTRL[7] distance_cm PWM_VALUE LED Bar

새 모듈

distance_to_pwm_value_controller.v

재사용

led_pwm_controller.v는 수정하지 않습니다.

모드

CTRL[7]로 UART PWM / 거리 기반 LED Bar를 선택합니다.

STEP 01

1. 거리값을 LED Mask로 직접 바꾸지 않는다

잘못된 확장 방향
distance_cm
→ Top에서 거리 비교
→ LED Mask 직접 생성
→ LED

이번 과제
distance_cm
→ distance_to_pwm_value_controller
→ pwm_value
→ 기존 led_pwm_controller
→ LED Bar

핵심은 이미 완성된 LED Bar 회로의 인터페이스를 유지하는 것입니다. 새로운 센서 데이터를 기존 pwm_value 형식으로 변환하여 모듈을 재사용합니다.

STEP 02

2. 수정 및 추가 범위

구분파일
추가distance_to_pwm_value_controller.v
연결만 수정basys3_uart_led_pwm_cds_ultra_fnd_top.v
그대로 재사용led_pwm_controller.v
수정 없음UART, CdS, FND, Register Map, 초음파 거리계, XDC
Top Module에는 거리 비교, LED 개수 계산, LED Mask 계산을 넣지 않고 하위 모듈 연결만 추가합니다.
STEP 03

3. 거리 → PWM_VALUE 변환 기준

거리led_pwm_value기대 LED Bar
10cm 미만0xFF16개
20cm 미만0xE0약 14개
30cm 미만0xC0약 12개
50cm 미만0x80약 8개
80cm 미만0x40약 4개
80cm 이상0x10약 1개
손이 가까움 → 큰 pwm_value → LED 많이 ON 손이 멀어짐 → 작은 pwm_value → LED 적게 ON
STEP 04

4. CTRL[7]로 LED Bar 입력 소스 선택

CTRL Bit역할
CTRL[0]LED PWM Enable
CTRL[2]초음파 거리계 Enable
CTRL[7]거리 기반 LED Bar Mode
 
CTRL[7] = 0
→ 기존 UART PWM_VALUE 기반 LED Bar

CTRL[7] = 1
→ 초음파 거리 기반 LED Bar

거리 기반 모드를 사용하려면 CTRL[0]=1, CTRL[2]=1, CTRL[7]=1이므로 CTRL=0x85입니다.

STEP 05

5. distance_to_pwm_value_controller

if (!distance_led_mode)
    led_pwm_value = pwm_value_reg;

else if (!dist_enable)
    led_pwm_value = pwm_value_reg;

else if (!distance_valid || timeout_error)
    led_pwm_value = 8'h00;

else if (distance_cm < 10)
    led_pwm_value = 8'hFF;

else if (distance_cm < 20)
    led_pwm_value = 8'hE0;

else if (distance_cm < 30)
    led_pwm_value = 8'hC0;

else if (distance_cm < 50)
    led_pwm_value = 8'h80;

else if (distance_cm < 80)
    led_pwm_value = 8'h40;

else
    led_pwm_value = 8'h10;
중요: 거리값이 아직 유효하지 않거나 Timeout이면 거리 기반 모드에서 LED Bar를 끄기 위해 0x00을 출력합니다.
STEP 06

6. Top Module은 연결만 변경

wire [7:0] led_pwm_value_selected;

distance_to_pwm_value_controller u_distance_to_pwm_value_controller (
    .ctrl_reg       (ctrl_reg),
    .pwm_value_reg  (pwm_value_reg),
    .distance_cm    (distance_cm),
    .distance_valid (distance_valid),
    .timeout_error  (distance_timeout),
    .led_pwm_value  (led_pwm_value_selected)
);

led_pwm_controller u_led_pwm_controller (
    ...
    .pwm_value (led_pwm_value_selected),
    .led       (led)
);

기존 led_pwm_controller.v 내부 회로는 변경하지 않고 입력만 pwm_value_reg에서 led_pwm_value_selected로 바꿉니다.

STEP 07

7. moserial 보드 확인

010085

CMD  = 0x01
ADDR = 0x00
DATA = 0x85

CTRL[0] = 1 → LED PWM ON
CTRL[2] = 1 → 초음파 ON
CTRL[7] = 1 → 거리 기반 LED Bar Mode
실제 거리기대 LED Bar
약 5cm거의 전체 ON
약 15cm많이 ON
약 25cm약 12개 ON
약 40cm약 8개 ON
약 60cm약 4개 ON
약 100cm약 1개 ON

기존 UART 직접 제어 모드로 돌아갈 때는 010001을 전송한 뒤 010180처럼 PWM_VALUE를 다시 직접 설정할 수 있습니다.

위 내용은 참고자료의 보드 확인 기준이며 이번 생성 과정에서 실제 Basys3 측정 결과를 새로 만든 것은 아닙니다.

핵심 정리

  • 기존 LED Bar 모듈을 수정하지 않고 초음파 거리값을 pwm_value로 변환해 재사용합니다.
  • CTRL[7]이 0이면 기존 UART PWM_VALUE, 1이면 거리 기반 값을 선택합니다.
  • 거리 기반 모드는 CTRL[0], CTRL[2], CTRL[7]을 함께 사용합니다.
  • 가까울수록 큰 PWM_VALUE를 만들어 LED Bar가 길어지고 밝아집니다.
  • Invalid 또는 Timeout에서는 LED Bar를 0으로 만듭니다.
  • Top Module은 거리 판단 없이 모듈 연결만 담당합니다.
