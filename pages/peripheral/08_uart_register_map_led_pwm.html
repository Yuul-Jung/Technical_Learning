RTL 주변기기 회로설계 · 08

UART Register Map · LED PWM Dimming RTL 실습

문자열 Command 대신 CMD · ADDR · DATA 3Byte 고정 Packet을 사용합니다. UART로 받은 Byte를 Register Write 신호로 변환하고, CTRL과 PWM_VALUE Register에 저장하여 LED 16개의 밝기를 제어합니다.

Register Map3Byte PacketCTRLPWM_VALUE8-bit PWM

Packet

CMD → ADDR → DATA 순으로 3Byte를 받아 Register Write 요청으로 변환합니다.

Register Map

0x00=CTRL, 0x01=PWM_VALUE 두 개의 Register를 사용합니다.

PWM

8-bit PWM과 Prescaler를 사용하여 LED 16개의 밝기를 동시에 제어합니다.

순서이름의미

현재 지원 CMD는 Register Write 하나입니다.

CMD_WRITE = 0x01
01 00 01 → CMD=Write → ADDR=CTRL → DATA=0x01 → LED PWM Enable
STEP 03

3. Register Map

AddressRegister기능
0x00CTRLLED PWM Dimming ON/OFF
0x01PWM_VALUELED 밝기 0~255
01 00 01 → CTRL = 0x01 → PWM Enable
01 01 80 → PWM_VALUE = 0x80 → 약 50% Duty

정의되지 않은 주소에 Write가 들어오면 기존 Register 값은 유지하고 reg_error를 1Clock Pulse로 발생시킵니다.

STEP 04

4. uart_reg_write_controller — 3Byte를 Write 신호로 변환

byte_index = 0 → CMD 저장
byte_index = 1 → ADDR 저장
byte_index = 2 → DATA 수신 + Write 판단
if (cmd_reg == CMD_WRITE) begin
    reg_wr_en   <= 1'b1;
    reg_wr_addr <= addr_reg;
    reg_wr_data <= in_data;
end
else begin
    cmd_error <= 1'b1;
end
reg_wr_en과 cmd_error는 상태가 아니라 사건을 알리는 1Clock Pulse입니다.
STEP 05

5. simple_register_map — 주소 해석과 Register 저장

case (reg_wr_addr)
    8'h00: ctrl_reg      <= reg_wr_data;
    8'h01: pwm_value_reg <= reg_wr_data;
    default: reg_error   <= 1'b1;
endcase
Register Write Interface → Address Decode → 실제 Register 저장 → Controller가 Register 값을 사용

UART Packet 해석 회로와 실제 LED 제어 회로를 직접 결합하지 않고 Register Map을 중간 제어 계층으로 둡니다.

STEP 06

6. led_pwm_controller — 약 1kHz 8-bit PWM

100 MHz ÷ (390 × 256) → 약 1001.6 Hz → 약 1 kHz
assign pwm_enable = (ctrl_reg == 8'h01);
assign pwm_active = (pwm_counter < pwm_value);

STEP 08

8. Testbench와 검증 메모

참고자료의 Testbench 기준대로 내부 in_data를 직접 자극하지 않고 Top의 RsRx에 실제 UART 8N1 직렬 파형을 입력하도록 구성했습니다.

UART Packet확인 항목
01 00 01CTRL = 0x01
01 01 80PWM_VALUE = 0x80
01 00 00CTRL = 0x00, LED OFF
검증 메모 1: 소스의 PWM 비교식은 pwm_counter < pwm_value입니다. 따라서 0xFF는 256 Step 중 255 Step이 ON이므로 정확히 100%가 아니라 약 99.6% Duty입니다. “최대 밝기에 가깝다”가 정확한 표현입니다.
검증 메모 2: 참고자료의 최신 uart_core 예시는 rx_out_data / rx_out_valid / rx_out_ready, tx_in_data / tx_in_valid / tx_in_ready 형태를 사용합니다. 기존 공개 04~07을 일괄 변경하지 않기 위해 이번 Top 소스는 현재 누적 사이트의 rx_data / rx_valid / rx_ready 인터페이스에 연결했습니다. Register Controller 자체는 in_data / in_valid / in_ready 표준 인터페이스를 유지합니다.
제공한 Testbench는 참고자료의 검증 구조를 코드로 정리한 것이며 현재 생성 환경에서 Vivado Simulation을 실제 실행한 결과로 표시하지 않았습니다.

핵심 정리

  • 문자열 명령 대신 CMD · ADDR · DATA 3Byte Packet으로 Register를 직접 제어합니다.
  • 0x00은 CTRL, 0x01은 PWM_VALUE Register입니다.
  • UART Packet 해석, Register 저장, PWM 출력을 각각 독립 모듈로 분리합니다.
  • 100MHz, Prescale 390, 8-bit PWM의 주파수는 약 1kHz입니다.
  • Top Module은 보드 핀과 재사용 모듈 연결만 담당합니다.
  • Register Map 구조는 이후 주변기기 제어 Register 확장의 기준이 됩니다.
