RTL 주변기기 회로설계 · 17

종합과제 · 모터 + XADC + 초음파 + CdS + LED RTL 통합

지금까지 만든 UART Register Map, LED PWM/Bar, CdS, HC-SR04, FND, XADC, L298 Motor 기능을 하나의 Basys3 시스템으로 묶습니다. 새 기능을 다시 만드는 단계가 아니라 기존 모듈을 유지하면서 Top은 Shell/Wrapper로 연결하고, 파일 구성·검증·보드 확인 절차를 완성하는 종합 단계입니다.

UART Register Map LED PWM / Bar CdS HC-SR04 XADC L298 Motor

핵심 원칙

기존 기능 유지 + L298 통합 + Top 연결 중심

검증

모터 Controller 단위 Test + XADC 구간 Test를 우선합니다.

배포

재사용 RTL을 Chapter 17 소스 폴더에 한 번에 모았습니다.

STEP 09

9. 누적 프로젝트 검증 메모

CTRL[7]: 종합 참고자료는 Reserved로 표기하지만 Chapter 13의 거리 기반 LED Bar 기능을 유지하기 위해 계속 사용합니다.
FND 거리 상태: 종합 참고자료의 초음파 예시는 -023, -120이지만 Chapter 12에서 이미 n023 / -050 / F120 상태 문자를 추가했습니다. 누적 사이트에서는 Chapter 12 기능을 유지합니다.
XADC 범위: 참고 회로의 약 0.7V 제한과 0~1V 전체를 0~9로 나눈 변환표 사이에는 범위 차이가 있습니다. 회로를 그대로 쓰면 실제 Volume 최대 숫자가 9까지 도달하지 않을 수 있으므로 보드 측정으로 검증합니다.
PC817: 절연형 PC817 회로에서는 GND1/GND2 분리와 Open-Collector 출력 반전 가능성을 확인합니다. 직접 연결형 L298 구성의 공통 GND 조건과 혼용하지 않습니다.
Simulation: 현재 생성 환경에는 Verilog Simulator가 없어 PASS: l298_distance_motor_controller test completed. 등의 문구를 실제 실행 결과로 표시하지 않습니다.

핵심 정리

  • Chapter 17은 새 기능 추가보다 기존 주변기기를 하나의 프로젝트로 통합하는 종합 단계입니다.
  • UART Register Map이 전체 시스템의 제어 중심입니다.
  • Top은 Shell/Wrapper로 유지하고 기능 판단은 각 Controller에 둡니다.
  • CdS, HC-SR04, XADC, L298, LED/FND 기능을 동시에 유지합니다.
  • XADC Wizard는 Vivado IP로 생성하고 xadc_wiz_0.xci를 Design Sources에 포함합니다.
  • 모터·HC-SR04·XADC는 보드 연결 전에 전압과 인터페이스 회로를 반드시 확인합니다.
  • Chapter 13~16에서 이미 확장한 기능은 종합 참고자료와 표기가 다르더라도 누적 사이트에서 삭제하지 않습니다.
