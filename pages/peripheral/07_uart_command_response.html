RTL 주변기기 회로설계 · 07

UART Command Parser · Response Generator RTL 실습

Echo에서 한 단계 확장하여 수신 Byte Stream을 LF 기준 Command Frame으로 만들고, LED=ON, LED=OFF, STATUS? 명령을 해석한 뒤 UART TX FIFO를 통해 응답 문자열을 반환합니다.

Line Receiver Command Parser Response Generator valid / ready Backpressure

Frame

Byte Stream을 LF(0x0A)까지 모아 하나의 명령 Frame으로 확정합니다.

Parser

Frame 길이와 각 ASCII Byte를 비교하여 지원 명령을 판별합니다.

Response

응답은 1Byte씩 out_valid / out_ready Handshake로 TX FIFO에 전달합니다.

STEP 02

2. uart_line_receiver — LF 기준 Frame 생성

L → E → D → = → O → N → LF → frame_len = 6 → frame_valid = 1 Clock 
if (in_data == 8'h0A) begin
    frame_valid <= 1'b1;
    frame_len   <= wr_index;
    wr_index    <= 8'd0;
end
else if (wr_index < MAX_LEN) begin
    frame_data[8*wr_index +: 8] <= in_data;
    wr_index <= wr_index + 1'b1;
end

기존 BRAM Line Buffer 실습과 역할은 비슷하지만, Command Parser가 문자열 전체를 바로 비교할 수 있도록 이번에는 frame_data 벡터를 Controller 인터페이스로 제공합니다.

STEP 03

3. 지원 Command와 Response

Command내부 동작Response
LED=ON + LFLED0 ONOK LED ON + LF
LED=OFF + LFLED0 OFFOK LED OFF + LF
STATUS? + LFLED0 상태 확인LED=ON 또는 LED=OFF + LF
기타지원하지 않는 명령ERR CMD + LF
LF(Line Feed, 줄바꿈)는 ASCII 0x0A이며 Command 문자열 자체 길이에는 포함하지 않습니다.
STEP 04

4. uart_command_parser — Frame을 명령으로 해석

assign cmd_led_on =
    (frame_len == 8'd6) &&
    (c0 == "L") && (c1 == "E") && (c2 == "D") &&
    (c3 == "=") && (c4 == "O") && (c5 == "N");

LED=OFF와 STATUS?도 같은 방식으로 Frame 길이와 각 ASCII Byte를 함께 비교합니다. 

if (cmd_led_on) begin
    led0_state   <= 1'b1;
    response_sel <= RESP_OK_LED_ON;
    response_req <= 1'b1;
end
else if (cmd_led_off) begin
    led0_state   <= 1'b0;
    response_sel <= RESP_OK_LED_OFF;
    response_req <= 1'b1;
end
else if (cmd_status) begin
    response_sel <= RESP_STATUS;
    response_req <= 1'b1;
end
else begin
    response_sel <= RESP_ERR_CMD;
    response_req <= 1'b1;
end
STEP 05

5. uart_response_generator — 문자열을 1Byte씩 출력

RESP_OK_LED_ON → O → K → Space → L → E → D → Space → O → N → LF

응답 문자열 전체를 한 번에 UART에 넣는 것이 아니라, 현재 index에 해당하는 한 Byte를 출력하고 뒤쪽이 받을 준비가 되었을 때만 다음 Byte로 이동합니다. 

assign out_data  = resp_byte;
assign out_valid = busy_reg;

if (busy_reg && out_ready) begin
    if (index == resp_len - 1'b1)
        busy_reg <= 1'b0;
    else
        index <= index + 1'b1;
end
STEP 06

6. valid / ready와 TX FIFO Backpressure

Response Generator out_valid → TX FIFO Full 확인 → 공간 있음: 1Byte Write → 공간 없음: 현재 Byte 유지 
assign response_ready = !tx_full;

assign tx_wr_data = response_data;
assign tx_wr_en   = response_valid && response_ready;

TX FIFO가 Full이면 out_ready=0이 되어 Response Generator가 현재 Byte와 index를 그대로 유지합니다.

STEP 08

8. 검증 기준과 Source 검증 메모

입력기대 내부 상태기대 응답
LED=ON + LFLED0=1OK LED ON + LF
LED=OFF + LFLED0=0OK LED OFF + LF
STATUS? + LF상태 유지현재 LED 상태 문자열

검증 메모: 참고자료의 명령표에는 기타 명령의 응답을 ERR CMD로 정의했지만, 같은 자료의 예시 command_parser_fsm.v는 기타 명령을 RESP_STATUS로 연결합니다. 이번 RTL은 명령표의 정의를 기준으로 RESP_ERR_CMD를 별도로 추가했습니다.
Testbench 파일은 Parser와 Response Generator 단위로 제공하지만, 현재 실행 환경에는 Verilog Simulator가 없어 실제 Simulation Output으로 표시하지 않았습니다.

핵심 정리

  • UART Echo는 Byte를 그대로 반환하지만 Command 단계는 LF까지 모은 Frame을 해석합니다.
  • uart_line_receiver가 Byte Stream을 Frame으로 변환합니다.
  • uart_command_parser가 LED=ON, LED=OFF, STATUS?를 판별합니다.
  • uart_response_generator가 OK, STATUS, ERR 응답을 Byte Stream으로 생성합니다.
  • TX FIFO Full 시 valid/ready Backpressure로 응답 Byte 손실을 방지합니다.
  • Top은 Shell로 유지하고 실제 기능은 재사용 가능한 Controller에 둡니다.
