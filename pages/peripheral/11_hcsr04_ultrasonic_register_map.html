RTL 주변기기 회로설계 · 11

HC-SR04 초음파 거리계 · UART Register Map RTL 실습

FPGA가 10us Trigger Pulse를 만들고, HC-SR04의 Echo HIGH 시간을 1us 단위로 측정하여 거리를 계산합니다. CTRL[2]로 초음파 기능을 켜고 끄며 거리값은 FND 하위 3자리에 표시할 수 있도록 BCD로 변환합니다.

HC-SR04 10us Trigger Echo Timing 1us Tick CTRL[2] Timeout

Trigger

us_trig를 10us 동안 HIGH로 출력합니다.

Echo

us_echo HIGH 시간을 측정합니다.

Distance

distance_cm ≈ echo_us_cnt / 58로 계산합니다.

거리(cm) ≈ Echo HIGH 시간(us) ÷ 58
거리Echo HIGH100MHz Clock Count

10cm약 580us약 58,000
50cm약 2,900us약 290,000
100cm약 5,800us약 580,000

현재 RTL은 100MHz를 먼저 1us Tick으로 바꾸고 Echo HIGH 시간을 us 단위로 셉니다.

assign calc_distance_cm_wide =
    echo_us_cnt / 32'd58;

원본 최신 Top은 표준 Byte Stream 이름을 사용하지만, 기존 공개 Chapter를 깨뜨리지 않기 위해 이번 Top은 현재 누적 사이트의 rx_data / rx_valid / rx_ready UART Core 인터페이스에 연결했습니다.

핵심 정리

  • HC-SR04 Trigger는 FPGA 출력이고 Echo는 FPGA 입력입니다.
  • Trigger는 10us HIGH, 센서는 40kHz 초음파 8 Cycle을 송신합니다.
  • Echo HIGH 시간을 1us 단위로 측정한 뒤 /58로 cm 거리값을 계산합니다.
  • Echo 입력은 2-FF 동기화를 적용합니다.
  • Echo 없음과 Echo 과다 지속을 각각 Timeout으로 처리합니다.
  • CTRL[2]가 초음파 거리계 Enable입니다.
  • HC-SR04 Echo 5V를 Basys3 3.3V 입력에 직접 연결하지 않습니다.
