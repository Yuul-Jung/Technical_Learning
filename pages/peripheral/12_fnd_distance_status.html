FND 초음파 거리 상태 문자 · n / - / F RTL 실습

Chapter 11에서 표시하던 초음파 거리값 앞에 상태 문자를 추가합니다. 30cm 미만은 n, 30~99cm는 -, 100cm 이상은 F를 표시합니다. CdS의 L/d가 활성화되면 기존 CdS 표시가 우선합니다.

FND BCD near / normal / far CdS Priority Top 수정 없음

Near

0~29cm → nxxx

Normal

30~99cm → -xxx

Far

100cm 이상 → Fxxx

STEP 04

4. BCD 값을 직접 비교

value_bcd는 이진수 거리값이 아니라 각 10진 자리를 4bit로 나눈 BCD입니다. 123cm는 12'h123입니다. 

assign distance_less_030 =
    value_valid &&
    (value_bcd[11:8] == 4'd0) &&
    (value_bcd[7:4] < 4'd3);

assign distance_ge_100 =
    value_valid &&
    (value_bcd[11:8] != 4'd0);
12'h023 → 백의 자리 0 → 십의 자리 2 → 30cm 미만 → n 12'h120 → 백의 자리 1 → 100cm 이상 → F
STEP 05

5. 최종 상태 문자 선택

assign distance_status_code =
    distance_less_030 ? CHAR_n :
    distance_ge_100   ? CHAR_F :
                        CHAR_DASH;

assign status_digit =
    status_valid ?
    ((status_code == CHAR_DASH) ?
        distance_status_code :
        status_code) :
    CHAR_DASH;

이 구조 때문에 기존 CdS L/d 로직을 건드리지 않고, 거리 전용 상태에서만 n/-/F가 자동 선택됩니다.

핵심 정리

  • 초음파 거리 숫자 앞에 n/-/F 상태 문자를 추가합니다.
  • 30cm 미만은 n, 30~99cm는 -, 100cm 이상은 F입니다.
  • 거리 판단은 BCD 백·십의 자리를 직접 비교합니다.
  • CdS L/d가 활성화되면 거리 상태 문자보다 우선합니다.
  • Top Module과 초음파 거리계는 수정하지 않고 FND 표시 모듈 내부 규칙만 변경합니다.
  • 하위 FND Testbench로 표시 정책을 먼저 독립 검증할 수 있습니다.
