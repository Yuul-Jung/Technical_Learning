1. Ubuntu에서 AMD Vivado 2024.2 설치
2. SW0를 이용한 LED0 ON/OFF 실습
3. 74 시리즈 기반 Verilog RTL 설계 가이드
4. 부울대수 공리 FPGA 실습
5. Level 1 논리게이트 FPGA 실습
6. 구조화 Gate Module RTL 실습
7. Verilog 기본 문법과 로직게이트 실습
8. Boolean Algebra · Karnaugh Map RTL 실습
9. 조합회로 설계 실습 — Adder
